# 分离读写路径与生成反馈（2026-10-03）

## 问题与修订来源

用户将目标具体化为两种能力：输入时“一目十行”，无需激活许多面向输出的模块；输出时，从内部状态进入生成模块，跳过底部读入模块。此前仅给出 E→R→D 或讨论严格可逆的价值，没有明确两种执行路径及其训练闭环，不能充分回应这一目标。

本轮提出可消融的候选执行路径：读入器 E、共享状态核心 C、生成器 D，以及复用生成过程信息的轻量写回器 W。这里的模块按职责定义，不假定已有 decoder-only 模型的底层和顶层天然具有这种分工。未实现模型或运行训练；以下架构、课程及收益预测均待验证。

相关前文：[模块池与多粒度读入](2026-09-30-module-pool-routing-and-multirate-reading.md)、[层深与输出阶段](2026-10-02-层深语义与输出阶段.md)、[可逆层与语义接口](2026-10-03-可逆层与语义瓶颈.md)。

## 对象、尺度、目标与假设

- 输入是已经给定的一段文本；输出是尚未产生、需自回归选择的 token。两种信息可见性不同。
- “一目十行”包含整体理解已知片段、让后文修订前文解释，以及在较粗粒度上调用深层核心。仅在 GPU 上并行 prefill 不充分满足这个目标。
- E 处理外部文本；C 在粗粒度状态上整合信息、推理与更新；D 负责在核心状态条件下输出细粒度文本；W 将刚写出的内容反馈到核心。
- 共享状态 S 可以是有限工作槽位或粗粒度序列加工作槽位。当前没有确定无限上下文接口，也没有证明有限 S 足以保留任意输入细节。
- 候选假设：一个局部生成段内，D 的缓存足以维持逐 token 依赖；C 可在段末或推理步骤边界更新。困难步骤可能需要更早回到 C，不能强制假设任意长输出都可由一次核心调用完成。
- 可观察量：阅读与生成质量、READ/WRITE 切换后的续答、逐字细节与长距离约束、E/C/D/W 的实际调用量、首 token 延迟、生成延迟、KV/活动内存以及训练成本。

## 两条执行路径：候选设计

### READ：外部文本直接进入核心

已知输入 X → E(X) → C → S；不调用 D。

E 在局部块内双向处理输入，并提供少量粗粒度状态。例如，32 个 token 生成 4 个状态仅是可消融的起始规格，不代表已知最优压缩比。C 可以在全部已知输入的粗粒度状态间双向交互，再形成可修订的工作状态；因而后文可以改变整段解释。

这种接口必须通过训练得到。已知输入中的未来内容可用于回答后续问题，但含这些内容的状态不能拿来预测同一输入中更早的 token。输入/目标切分及 mask 必须把两者分开。

若压缩后的 S 不足以保留随机名称、数值、否定或逐字引用，候选是保留不可变细节缓冲，按需查询原片段。查询计算和存储应计入总成本。不能把“只保留少数状态”直接解释成无损理解。

### WRITE：从核心进入生成器，生成信息直接写回

S → D 逐 token 生成 y → W(y, D 的局部缓存, S) → C → S_next；不执行完整 E。

D 仍需要把实际选择的上一 token 送入自身局部缓存，通常只需 embedding 和局部生成计算。每完成一个块或一个推理步骤，W 复用这些缓存及实际 token，形成核心更新；下一步输出或思考再使用更新后的 S。起步可用明确的步骤分隔符，随后测固定块长和更灵活边界。

这里有一个关键区别：采样前的 hidden state 表示对可能输出的条件分布，不保证标识最终选中的 token。因此 W 必须获得实际输出；最后一个 token 即使尚未被 D 作为下一步输入，也要纳入写回。只把采样前 hidden state 当成已经写出的意思会漏掉分支选择。

W 可以先用一层汇聚/交叉注意力，把 token embedding 与相应生成缓存变成与 E 相同规格的少量更新。它本身有成本；候选收益是避免完整的语义读入计算，而非宣称输出完全不处理 token。

核心状态改变时，依赖旧 S 的生成器 cross-attention 缓存要更新或失效；最小实现可在块边界重建相关缓存，并重置块内局部缓存。由此产生的启动和桥接成本必须测量。

### 共享核心为什么需要写回

若 C 在生成期间保持固定、全部后续推理都留在 D 的缓存中，普通 encoder–decoder 已可实现输入不走 decoder、输出不走 encoder。额外 W 的目标是让 C 能继续使用自己刚写出的推理结论，并支持生成后再阅读新输入的模式切换。

还有一个无需对每段文字写回的条件情形：若 C 先在内部完成一次推理并保留新状态，D 仅负责可靠表达该结论，C 可继续使用已有状态。但这要求输出忠实于内部结论；随机选择、生成中的新推理或表达错误不能自动被 C 知道。W 不是两种执行路径的逻辑必需条件，而是核心需要获知实际生成内容时的候选闭环。

“外部读入”和“自行写出”需要在同一前置状态、同一内容和同一角色下产生兼容的后续行为。不要求两者张量逐维相等，也不把模型自己的假设提升为外部事实。读入参照分支应带与写回分支一致的 assistant/thought 等来源标记。

## 训练闭环：以可靠预训练接口为前提

### 预训练起点已修订

用户随后指出，前缀双向读入、后缀输出的方案接近 T5，而且这里尚未回答 D 与整个模型如何预训练。该批评成立。此前指定的随机前后缀切分属于 Prefix LM，可作为候选目标，但不再把它直接作为默认课程。

接续见[统一自回归预训练与读写分工](2026-10-03-统一自回归预训练与读写分工.md)：将所有文本块轮流作为目标，对全部有效 token 计算自回归损失；完整历史块经 E/C 为下一块提供条件，E/C/D 联合训练。先检验这一因果基线的质量、接口和成本，再评价整体双向 READ 与输出免重读。

### 条件性的后续实验：训练 W 替代重读


对同一个前置状态 S 和同一个已经完成的输出块 y，构建两条分支：

- 参照：S_E = C(S, E(y, S, role))。
- 候选：S_W = C(S, W(y, cache_D, S, role))。

先固定已训练的 E/C/D，仅训练 W。两条分支都只见到已经输出的 y，不见下一段目标。用 S_W 的后续输出交叉熵，以及 S_E 与 S_W 对后续 token 或任务的预测分布一致性训练 W；参照分支停止梯度。后续可以共同微调，但不作为首个判别实验的必要步骤。

不优先使用裸 hidden-state MSE：向量坐标不同可以有相同有效含义，而数值接近也可能漏掉影响答案的小细节。当前主要检验的是后续行为与任务质量，不能把预测一致性声称为全部语义等价的证明。

训练初期可使用 teacher-forced 输出块，但必须在自由生成及多块滚动下验证，并逐步加入模型实际产生的轨迹。只在正确示范输出上对齐，不能保证错误、自我修正和随机采样后也能正确写回。

## 核查的研究先例与界限

### Block Transformer：最直接的计算路径先例

[Block Transformer（NeurIPS 2024）](https://arxiv.org/abs/2406.02657)将轻量 embedder、全局 block decoder 与局部 token decoder 分开。已知 prompt 中已完成的块无需运行 token decoder；最后一个未完成块有例外。token decoder 在局部块内生成，深层全局网络在块尺度工作。见[论文 §2、§3.8](https://arxiv.org/html/2406.02657v2)。

作者实现生成每块后仍将实际 token 送入 embedder，见[代码中的 re-embed next block](https://github.com/itsnamgyu/block-transformer/blob/main/model/block_transformer.py#L375)。因此它没有验证本轮提出的生成缓存写回器 W。不过其主要 embedder 是便宜的 embedding 查表与拼接，本身已经避免了输出时重复执行深层读入网络；若 E 只是这样简单，W 未必值得增加。

论文主要使用短固定块，不能据此声称“一目十行”的长片段理解、双向输入修订或本项目的共享工作记忆已实现。也不能把作者在特定批量与 KV 条件下的吞吐收益直接换算成当前单请求加速比。

[论文 §4.2](https://arxiv.org/html/2406.02657v2#S4.SS2)报告用 MSE/对比目标预测下一块 embedding 的尝试损害性能，并提出连续块误差累积问题。这不是对 W 的直接否证，但提醒不能把中间向量预测容易训练当成已知事实。

### H-Net、BLT 与 Perceiver：相关但未验证完整目标

- [H-Net（2025）](https://arxiv.org/abs/2507.07955)以动态分块降低核心更新频率；生成时细粒度 encoder/router 仍逐 byte 执行，不提供输出跳过该读入路径的证据。
- [Byte Latent Transformer（ACL 2025）](https://aclanthology.org/2025.acl-long.453/)有 local encoder、global transformer、local decoder；decoder 依赖此前 byte 的局部编码状态，不能直接当作省掉输出读入器的实例。
- [Perceiver IO](https://arxiv.org/abs/2107.14795)提供读入、latent 核心和查询式输出的清晰分离；[Perceiver AR](https://proceedings.mlr.press/v162/hawthorne22a.html)支持长输入与较少深层 latent 的因果生成。它们不直接验证本轮持久状态的写回与模式切换。

## 最小反例、对照与收益预测

最小任务族：输入多个实体传递关系，末尾修订一条较早的关系；模型分步生成一个中间结论，再接收新条件，回答必须使用此前确实生成的结果。另设随机名称、数字和否定条件，避免只凭大意完成任务。来源和角色固定；输入的后文修订只发生在已知范围。

更直接的生成反馈检查：让 D 在合法的红/蓝方案中随机选择一个并实际输出，然后清除 D 的局部缓存，禁止下一问直接查询原始生成文本；经新一轮 READ 给出“红方案用规则 A，蓝方案用规则 B”，要求依据实际选择续答。输出前的 S 不能确定随机选择，若 S_next 仍能正确处理，才说明实际 token 的信息进入了共享核心。该限制用于诊断接口；正常产品是否允许查询生成原文是另一设计选择。

应比较：

1. 相同数据及质量/资源预算下的普通 decoder-only 或常规 encoder–decoder。
2. 分块 E/C/D 参照：输入不走 D，输出每完成块后经 E 重读。
3. E/C/D/W：输出用 W 替代 E。
4. 停用写回：后续只靠 D 缓存；通过 READ/WRITE 切换及重建 D 缓存检查 C 是否掌握已写内容。

可证伪的收益预测：若 E 的确承担比 W 更贵的语义读入，在保持下一块预测及模式切换任务质量的条件下，第三种应减少输出时的 E 调用和端到端成本。若只减少计数而延迟不降，或质量仅在重读 E 后恢复，则“复用生成过程可省去读入”的主张在该设置下失败。

输入侧独立测：关闭 D 时，已知后文仍能修订整段解释；粗粒度 C 是否降低成本，以及随机细节是否迫使模型经常查回原文。不得用仅生成侧加速证明阅读侧成功。

按块更新会延迟 C 获知当前生成内容。若推理经常要求中途访问全局状态，应缩短块、允许边界重入或调整分工，并把额外调用计入成本；不能靠生成器越来越大掩盖核心被跳过后的能力损失。

## 可逆性在这个目标中的位置

本轮给对称性补充了功能目标：阅读将文本纳入工作状态；写出利用已有生成计算更新同一工作状态，避免重做阅读。最小约束是两种入口产生兼容的后续行为。

严格可逆可能使连续的“展开—收回”张量有精确关系，但 token 采样、变长序列和新内容仍需处理；并不自动使实际输出块具备这种关系。它也不能用更少总维度无损保存任意内容。当前无需改变前文“不优先硬性绑定底顶互逆”的判断，下一步优先比较重读 E 与轻量 W；若可逆结构对写回质量或成本有独有收益，再单独加入对照。

## 暂定结论与未决问题

两项能力可以定义成分离且共享核心的 READ/WRITE 路径；完整双向读入和输出免重读的联合收益尚未证明。用户指出预训练问题后，当前先验证全位置监督的分块自回归 E/C/D 基线。W 的正常重读参照训练与消融保留为条件性的后续实验，不再作为首个实验。

未决：E 是否需要深层语义处理；块长度/步骤边界；共享 S 的容量、细节缓冲与可修订方式；角色信息；W 在采样和多步误差下的稳健性；核心更新频率与生成器容量的权衡。当前研究顺序已修订为先回答联合自回归预训练，再考虑 W、整体输入修订及其他路由；该顺序不是已证明最优。
