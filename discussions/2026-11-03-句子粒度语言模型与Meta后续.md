# 句子粒度语言模型、Meta 后续与 B 接口

日期：2026-11-03（America/Los_Angeles；11 月 2 日开始核查）。状态：一手论文、官方代码与资产元数据核查；没有训练、下载新权重或运行句子模型。本轮接续已完成的 [H-Net 两级节点率探针](2026-11-02-HNet权重下载与层级码率探针.md)，不改动研究分支。项目比较依据仍是 [v1.2 固定提交](https://github.com/Jack31098/ai-modeling/blob/1ff300bfbb9a8ebb7bee242a0cbc37848fa6e190/path_control_pretraining_part1_v1.2.md)。

## 问题、尺度和证据边界

问题是：H-Net 在小样本中仍多为词／短语跨度，是否意味着句子粒度推理不可行；FAIR/Meta 及后续团队实际上做到了什么；哪些机制能与本项目 B⁺/B⁻ 比较。

本轮区分三个对象：句子编码器能否保留可用信息；主干能否根据过去预测下一句的表示或内容；解码器能否将条件表示落实为正确文字。可观察量分别包括检索／重建、真正自主续写／任务指标、精确符号保真，以及多步反馈的一致性。它们不能互相替代。

“句子”在这些工作中大多是外部分句器给出的单位，不是已验证的最优语义原子。一句可能包含多个事件，一个短语也可能需要很大上下文。LCM 的 two-tower 是上下文网络和去噪网络，**不等于 H-Net 的两次序列压缩**。

H-Net 本机 306→95→38 的结果限定于原版两级 L、该英文样本和编码路径：48 个空格词对应 95 个一级节点，一级实际上细于词；二级平均约 8 字节。边界跨度不等于 hidden 的全部历史依赖。它没有直接测试句子瓶颈，更没有比较句子切分目标、句子 codec 或逐句生成课程，因而不能证伪句子模型。[本机实验范围与数据](../experiments/hnet/README.md)。

## 先按真正预测的对象分类

| 路线 | 主计算／预测单位 | 文字怎样产生 | 能证明什么／不能证明什么 |
|---|---|---|---|
| SONAR、OmniSONAR | 已知完整句子→连续向量；检索、对齐及重建 | 条件于向量的文字 decoder | 是可用 codec 的证据；自身没有下一句先验。 |
| 原始 LCM、Mimir | 因果前缀句向量→下一句连续向量分布 | SONAR 在句内逐 token 解码 | 真正的句子向量自回归；仍需承担句内解码与扩散采样成本。 |
| SONAR-LLM | 因果前缀句向量→下一句向量，以解码后的 token CE 训练 | 冻结 SONAR decoder；公开推理将生成句重新编码回灌 | 是另一种句级训练目标；公开闭环并非直接接续预测 latent。 |
| Spectrum（OmniSONAR 论文 §9） | 文档先变成句向量序列，再由 token tower 预测文字 | token 自回归与 cross-attention | 最终是句表示输入、token 输出；只有预热阶段预测下一句向量。 |
| H-Net、DLCM | 细 token／字节编码、动态缩短主干序列，最终预测下个细 token | 细粒度 decoder；存在细路径 | 粗粒度计算，不自动等于独立的句子生成码。 |
| NCM | 离散多尺度码，按粗到细的层级生成，同层并行 | 最后由冻结 codec 恢复 token | 是层级码生成先例；不是逐句从左到右预测。 |

分类依据为下列原论文与固定代码，而不是名字中的 concept、reasoning 或 semantic。它们覆盖了不同目标，不能排成一个统一质量榜。

### 输入、目标与反馈如何隔离

**原始 LCM：** 训练时完整目标句可用于构造该步 latent 标签；因果主干只接收已知前缀句表示。推理时在连续空间采样下一句向量，再由 SONAR 解码文字。[官方 generator](https://github.com/facebookresearch/large_concept_model/blob/fd7db8022113ae2d2ff1219d9a4cb4def897e3ff/lcm/inference/lcm/generator.py#L267)的 `finalize_step` 把模型向量写回 `self.seqs`，下一步读取它，不必先解码再编码。这支持“直接 latent 接续可实现”，尚不保证落地文字与计划一直一致。扩散的每句多次去噪也不能计作主干仅一次廉价调用。

**v-LCM：** 图像／视频表示与文字指令表示串接成前缀，two-tower 预测后续表示；SONAR codec 固定（§2.1）。旧 LCM 接口支持原 SONAR 1；OmniSONAR 的较强检索成绩不意味着可以零适配替换坐标空间。视觉 encoder 的对齐课程为图像→合成视频→人工核查视频，不是本项目逐轮剥离 F 的课程。[方法](https://arxiv.org/html/2603.01096v1#S2)。

**Spectrum：** 每个已知输入片段先独立编码，SONAR tower 上下文化，Llama token tower cross-attend；问题、选项与答案仍可作为英文 token 出现在 decoder。训练先预热下一句表示，再以句内 token CE 训练，随后 Prefix-LM，最后 SFT。前两阶段有句级因果 mask；最终输入塔双向读取已经给定的文档，输出塔仍因果。不能将这种合法文档理解方式当作流式 READ_STREAM 方案。正文 §9.1 报 SONAR tower 约 5B，计 cross-attention 的新增部分约 6.5B，另有 3B token tower 和前置 codec；表中“6B-3B”不是一个总共 3B 的系统。[架构与训练](https://arxiv.org/html/2603.16606v3#S9)。

OmniSONAR 另外研究 token 表示和长文本表示（§10），后者用于段落／文档 mining 的适配与难负例评估；仍不能写成“递归生成段落 latent 已获验证”。

## 独立后续：可运行资产与目标变化

**SONAR-LLM，FusionBrain 团队，不是 Meta 的 LCM 新版。** [v2，2026-05-25](https://arxiv.org/html/2508.05305v2)的主干输出下一句向量，经过冻结 decoder 以 token CE 反传。冻结 decoder 参数不等于阻断对输入向量的梯度；[训练代码 `SonarLossWrapper`](https://github.com/FusionBrainLab/SONAR-LLM/blob/155a899b43d14f4e5834eb7dfcd14ad1d7fa56d5/train_sonarllm.py#L156)可核实。主干训练时下一步仍喂真实前句编码，句内也用 teacher forcing。

关键实现事实：[公开 `generate.py` 第 68–78 行](https://github.com/FusionBrainLab/SONAR-LLM/blob/155a899b43d14f4e5834eb7dfcd14ad1d7fa56d5/generate.py#L68)得到 `next_embedding` 后，实际追加的是生成文字重新编码的 `embedding_re`，停止判定也使用后者。因此论文的“预测向量”和公开部署的“回灌向量”必须分开；不能用它证明无文字重编码的长期闭环。官方 README 链接 100M/300M/600M/900M 的 Drive 检查点；本轮未下载、校验或运行这些文件，也未定位 v2 新增 1.3B 结果对应权重。

**Mimir，Bari 团队，独立多语 LCM。** [v2，2026-09-14](https://arxiv.org/html/2605.25263v2)使用 two-tower diffusion 和 SONAR，语料为 46 语言约 38.9B 句、指令集 35 语言约 66.8M 句。§4 把目标概括为向量 MSE，但同节指定 two-tower，§5 及模型卡均使用 40 步 diffusion；本轮据此将 MSE 解读为扩散重建目标，而非单点回归，训练目标的完整实现仍应在复跑时验证。作者给出句分割、训练参数和模型使用范例，仍未在本机复现其训练。

本轮确认以下 HF 仓库包含实际 `model.pt`，而非只有模型卡；仅查元数据，不把 LFS 公告哈希称为本地校验。论文量化结果为 1.6B，不能移给较新 7B：

## 命名相近但不同的问题

[DLCM v2](https://arxiv.org/html/2512.24617v2)的动态边界、短主干与 token 解码更接近 H-Net；§3.3 的 R=4 表示约四个输入 token 一 concept，§3.5–3.6 最终仍为 token 生成。§8.1 还比较可训练预测器与基于已学习表示的固定相似度规则，并报告前者压缩率漂移；“动态”不必等于边界规则本身完全由任务损失训练。它能比较压缩率／边界学习，不能充当句子级先验成功的证据。

[NCM v1，2026-10-09](https://arxiv.org/html/2610.14162v1)先训 multiscale residual VQ codec，再冻结它训练按层级生成的 Transformer；有[官方代码](https://github.com/HazyResearch/ncm/tree/c70274273f489abc73832b2b98584a8483b6b203)和[检查点](https://huggingface.co/collections/hazyresearch/ncm)。Table 2 的无 guidance XSum 为 28.0 ROUGE-L／8 NFE，AURORA-LM 26.6／128 NFE；WMT14 则 22.6 BLEU，低于所列 AR 的 25.2。§I 明确固定尺度深度与长度、codec/生成目标分离、规模有限及粗层过渡伪影。这里 NFE 是整层码预测，不能同逐 token／逐句调用直接等价计费。它提供“多尺度离散码先学再生成”的相关基线，不是本项目的可变 child 调用协议。

## 与 H-Net 和 v1.2 的逐项比较

| 维度 | 公开 H-Net | LCM 系列／Spectrum | v1.2 规定；尚待实现验证 |
|---|---|---|---|
| 边界与抽象单位 | 从 token 任务学边界，有压缩率约束；模型尺度数预设。 | LCM 主要用外部分句；Spectrum 也可能整段输入。句子是规约选择，不是被发现的程序。 | 版本固定的参考结构监督动作，允许长期采用；随后检验控制接管。 |
| 表示里装什么 | 边界处有上下文化 hidden，不是独立语义符号；保留细路径。 | SONAR 优先可解码／跨语表征，语法、数字等保真依 codec；Spectrum 能额外读取 token 提问。 | 不强制同义 latent 相等；连续载荷由学生计算，任务与文字损失训练。 |
| 因果可见性 | 字节因果路径；旧式边界的时序不能当任意离线分块。 | 已知前句完整编码合法；预测的目标句仅作标签。Spectrum 最终双向输入塔仅限给定文档。 | READ_STREAM 逐事件可见性，READ_FULL 与之分开；禁止未来目标 latent 提前进入父计划。 |
| 训练课程 | 预设层级联合训练，公开复现交付有缺口。 | LCM 冻结 codec 后训 prior；SONAR-LLM 从 decoder CE 反传；Spectrum 多阶段接口适配。 | 每轮从完整 M 出发新增尺度并联合适配 F/B/相关 A/D；旧 B 冻结是比较项。 |
| 细粒度条件与绕行 | encoder→decoder skip 和外围状态可承担细信息。 | 原 LCM 句间无原 token skip，句内仍有自回归 token；Spectrum 问题／选项及自产输出在 token tower。 | 局部可用细节、QUERY、RETURN 有权限／寿命；不能依靠未经声明的永久明细库。 |
| B⁺ / B⁻ | encoder/router/downsample、dechunk/decoder 只有功能类比。 | 句 encoder / decoder 是一粗一细的接口；不是有 scope 的子程序。 | B⁺ 组合开放单元；B⁻ 创建 child、消费实际 RETURN，结果能改变后续调用。 |
| 生成反馈 | 每字节更新外围；选中边界才进内层。 | LCM 直接续接预测向量；SONAR-LLM 公开脚本解码再编码；Spectrum 在 token decoder 中续写。 | 已提交 latent 历史直接接续；下层实际新信息按 RETURN／COMMIT 提升。 |
| 耦合与可逆性 | 普通残差／skip，不等于正逆共享。 | SONAR 是学习型有损 codec，没有相同局部结构性逆约束。 | A/D 双路加法耦合在同参数／条件下结构正逆；B 有损，不要求 B⁺/B⁻ 数学互逆。 |
| 遗忘与精确性 | 外围 SSM 固定状态、中层局部 attention、内层粗 KV；并非各层存全字节。 | 句压缩可能丢细节；主干句 KV 不自动等于主动遗忘协议。 | A/D 窗口、B 缓冲有界；scope 生命周期显式；F 已提交 KV 按会话规则保留。 |

这些是相对公开设计的接口比较，不能用来判定 Cartesia 私有系统一定与我们不同，也不能把本项目设计要求当作已实现优势。

## 推演、反例和下一步

**暂定结论：** 现有证据足以否定“句粒度完全训练不动”这种过强结论。它支持有任务边界的句级表示与句级主干；没有证明一个固定句向量能承载所有精确细节，也没有证明任意层级递归压缩后仍有通用推理与保真。Meta 的 v-LCM 延续下一向量生成，Spectrum 另试句输入／token 输出；并行路线不等于某一路已被判失败。

**本项目假设：** 参考结构和逐尺度适配可能降低路由／接口学习难度；实际 RETURN 可能缓解粗计划与下层落地结果不一致。以上没有由现有论文或本项目实验直接证实。反向风险是：参考切分会错配任务信息，有限窗口永久丢掉未来要用的细节，低学习率旧接口也可能坐标不兼容。外层“有遗忘”本身不是优势。

最小反例保留三个独立观察：

1. **语义区分与符号保真：** “甲欠乙 3179 元”与“乙欠甲 3179 元”、“甲不欠乙 3179 元”、金额 3178。先测真实编码的重建／读取，再测预测编码与后续任务。语义相近不能替代角色、否定或数字正确。
2. **多步反馈一致性：** 父计划仅规定“选一个颜色”，child 实际落地红或蓝；后续问题必须依实际选择。分别比较直接计划 latent、生成句重编码、合法实际 RETURN。计划被解码器改写后仍沿用旧 latent，是可观测失败；教师事先塞标准颜色也算失败。
3. **遗忘和组织的独立价值：** 编号出现后跨过局部窗口，再要求精确引用。按 F 是否已 COMMIT、scope 是否可 QUERY／EXPIRED 分组；单级与多级有相同信息和容量对照。额外旁路能看明文的组不能用来证明 latent 瓶颈成功。

未来实验优先次序是接口可核验性：Mimir-1.6B-Instruct 可作为有权重的真正下一句向量基线；SONAR-LLM 可检验 CE 经 decoder 的目标及重编码反馈；H-Net 已有路由探针可作细路径对照。先固定检查点、codec、分句器、sampler 与输入权限，再分开验收 codec、teacher-forced prior、自主多句生成、RETURN 干预与总成本。本轮只给出方案和资产入口，未启动上述工作。
