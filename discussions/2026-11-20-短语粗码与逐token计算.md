# 短语粗码需要哪些前缀，能省下哪部分计算

2026-11-20。讨论对象是候选一的短块生成和跨块接续。本轮核对了设计与论文，未训练模型。下文的实验与取舍是讨论提案。

## 从哪里发生了变化

v1.21 已允许全局主干 F 发出一次条件，等待多次局部执行，再接收实际结果。v0.2 增加了一条更强的假设：小主干 G 和生成头 g 根据此前的粗码产生完整的新粗码 z；后续任务可以直接消费 z，文字可以稍后再展开。v0.2 将三条表示路线和训练顺序纳入同一接口，接替 11 月 19 日的 v0.1 工作草稿。[v1.21 §3.1](../path_control_pretraining_part1_v1.21.md#31-完整尺度接口与双向信息流) · [v0.2 §1–2](../coarse_grained_language_interface_candidate1_v0.2.md) · [v0.1 历史草稿](../continuous_state_framework_candidate1_v0.1.md)

要回答“能不能不用前缀”，先区分三种信息。生成下一块时，G 读此前已经完成的块。展开本块时，v0.2 的参考解码器 D 读 z 和本块自己已经输出的 token，从 BOS 起步。跨块接续时，G 直接接收生成的 z，运行协议禁用已展开文字的反馈。若用户从块中间给出一个外部前缀，后文仍是未知量；评估这种续写，可以在输入结束处关闭短块。把真实后文编码进 z 再补全，会泄漏答案。[v0.2 §2.2、§2.6、§2.16–17](../coarse_grained_language_interface_candidate1_v0.2.md)

## 原理与最小反例

设短语只有 AB 和 BA，两者等概率。生成器可以抽一比特选定整块，局部解码器据此同时写出两个位置。一个共同选择就保留了词序和两个位置的依赖。反过来，若粗码只保存“有 A 和 B”，再由 D 独立地等概率选择顺序，下一块只读这个粗码，判断实际首字的最优正确率是 1/2。固定解码规则能让结果唯一，但下游能否低成本算出该结果仍需验证。

对固定长度、给定合法历史 h 的离散文本块 X，可逆确定性编码满足 H(E(X) | h) = H(X | h)。精确改写表示会保留需要决定的信息量。这个等式没有规定运算次数。比如一串独立公平位可以并行抽样；反过来，从一长段上下文中复制一个指定编号，条件熵可以为零，定位、传送和读取它仍需工作。有限容量、有限精度的实际学习型编码需要单独测整块误差及罕见字段。

## 逐 token 的理由与实验证据

典型因果 Transformer 在每个位置维持一个上下文化向量。一个位置可以综合此前多个词的关系。逐 token 预测让训练语料中每个位置都有直接标签，也让生成器在每次采样后取得确定的符号，再据此分配下一项的概率。在草稿式推理中，上一步写出的中间结果还可触发一次新的深层计算。粗模型若减少这种机会，可能需要在生成头或局部模块内补回。这里是架构分析，不能据此断言所有语料都需要固定次数的深层计算。[Transformer §3.1–3.2](https://arxiv.org/html/1706.03762v7#S3)

BLT 的重型主干按字节块工作，轻量解码器依据实际已生成的字节继续预测。这给出了全局更新频率低于文字输出频率的实例。Meta 的 LCM 进一步以句向量为生成单位，原论文也指出 SONAR 表示对数字、代码等内容的保真较脆弱。两种结果覆盖的能力不同。[BLT §3](https://arxiv.org/html/2412.09871v1#S3) · [LCM 的表示分析](https://arxiv.org/html/2412.08821v2)

CALM 提供更贴近本问题的对照。在 K=4 的已知块上，解码器从 z 并行读出各位置，报告逐 token 重建准确率超过 99.9%。同论文表 5 比较下一步输入，在其配置中，单层线性投影直接输入预测向量的 BrierLM 为 3.25，先恢复离散 token 再嵌入、压缩为一个主干输入时为 4.70，越高越好。两项指标测的是不同问题。该消融对直接读取敲响警钟，仍留下输入适配器、表示训练目标和多步稳定性的解释空间。[CALM §2、§3.3.3、表 5](https://arxiv.org/html/2510.27688v1#S7.T5)

## 暂定判断与可证伪的比较

我赞成先研究接口，把“粗码提前确定内容且能直接接续”当作待验证假设。v1.21 的实际结果上返是重要对照。任务若只关心大意，逐字保真属于额外要求；任务若随后引用刚刚发出的编号，精确区别必须对后续计算可得。单靠重建成功或主干调用次数下降，都不足以支持净收益。

在相同训练文本、可见信息与输出要求下比较三条路径。A 是逐 token 的全局主干；B 和 C 采用相同块边界与全局更新频率。B 在块内逐 token 作出选择，把实际生成内容对应的状态交回主干；C 直接生成粗码并用它接续，按需展开文字。可增设结构性无损打包的对照排查编码损失。

让模型从两个未见编号中任选其一，接着追问所选编号或它绑定的角色。清除第一段旧缓存和原提示，各路径只保留其刚生成的结果，通过本身的接口交给下一步。记录合法性、两支覆盖、是否精确引用实际选择，并分别报告已知块重建、生成结果接续、相同质量下的完整计算和整段延迟。多步采样、局部解码和回传都计入。若 B、C 相对 A 均好，而 C 没有超出 B，已有证据只支持降低全局更新频率。若 C 在短块和受控任务上已需文字反馈或近似全主干成本才能追平，应降低对该配置的投入。真实语料中这两类情形各占多少仍待测。
