## 最新口径与对象

用户后续明确：先训练 B 规约器，F 与最终展开器从头训练，0.8B 是目标参数规模，不复用 Qwen 0.8B 主干。本次按此准备数据，不采用冻结预训练 Qwen codec／F 的替代路线。此执行选择优先于历史的 F 继承训练设想；v1.2 原文不改，沿用其 §10 的来源、事件、因果可见性和监督隔离要求。

本步对象是首层固定词边界：规则定义的字词、数字、URL 与显式保留的空白／标点／符号单元；不等于唯一语言学分词，也不证明语义规约。可观察量是无损跨度重建、来源及 split 隔离、监督时间是否合法、token 对齐冲突、确定性重跑及可检查样例；没有神经 B 的质量结果。

实现位于 [training/word_boundary_v0](../training/word_boundary_v0/README.md)。采用 Python 3.12.14、jieba 0.42.1，固定词典 SHA-256、关闭 HMM／用户词典，英文规则单独版本化。依赖安装在忽略的项目内 `.venv-word-boundary/`，没有安装模型框架或使用 GPU。

## 实际来源与规模

真实摘录来自 [Alice's Adventures in Wonderland，ebook 11](https://www.gutenberg.org/ebooks/11)和[《論語》，ebook 23839](https://www.gutenberg.org/ebooks/23839)，完整源文件约 263KB，仅用于校验与连续摘录；原文、固定更新版、获取日期、完整 hash、字符／字节提取范围和许可见[provenance](../training/word_boundary_v0/inputs/provenance.json)。源站标美国公版，未宣称全球权利；署名、原始完整许可和再分发通知随样例交付。27 条自写／合成夹具标 CC0，jieba 按 MIT，二者不混为真实语料。

29 条输入保留 26 条：21 train、2 dev、3 test，按隔离组为 18/2/2；固定 128-code-point 窗口共 37 片。1 条精确重复剔除，2 条空／全空白记录隔离。模板与近重复连边合并为共同 split，变体不当同义句删除；未知派生引用直接失败。审计包含逐条原因和未分配隔离记录，不只给最终数量。

真实英文摘录 1360 code point，中文摘录 138；两条都分入 train，dev/test 只有夹具。没有调种子迁就样例分布，因此不能用本次测试宣布真实分词泛化。中文原作是传统文言，不是现代简体中文质量样本。英文／中文／混合文本的 code point、byte、单元／词类长度、边界率及句末标点候选分别见[统计](../training/word_boundary_v0/sample_release/statistics.json)。

## 可见性、切片与对齐约定

Observation 只提供已到达的字符和实际收到的结束信号；参考边界与来源仅在独立 Supervision／审计文件中。消费器模型输入使用固定白名单，不包含全文长度、来源／split、标签、未来 mask、latent 或答案。消费时钟来自观察事件，去掉标签仍产生同样的模型输入帧。

离线完整分词标签限 READ_FULL。英文流式政策等待非 Han 空白分隔块后的第一个空白；末块要等真实 EOF 到达 N+1，而不能在最后字符 N 时偷看“没有后续”。已加入 N 时同前缀继续增长与 N+1 真 EOF 的对照。中文 jieba 依赖后文的汉字段不产生可强制流式动作；中文文档内独立 ASCII 编号按非 Han 政策处理。未设置最大块长，尚不满足部署所需的有限 buffer／延迟预算，不能把该基线称为完整因果 B。

原始书籍摘录结束不是书籍 EOF；128 字符切片也不注入 EOS。切片按原文字段固定，不以目标边界选择长度；跨窗单元显式 mask，并要求合法前缀重放／实际前置状态。离线结构不能作为过去状态的免费输入。

模型无关 token-offset 接口支持明确声明的 code point、UTF-8 byte、UTF-16 code unit 坐标；报告边界在 token 内、多边界共 token、覆盖重叠／空洞、Unicode 截断、special token 占文本和规范化错位。没有静默吸附。本步只运行人工适配夹具，没有选择真实模型 tokenizer，不能称为 Qwen/3B 的 token 对齐成功。

## 暂定结论、失败条件与下一步

已证明这个小样本上的数据合同、确定性规则和观察／监督隔离可以实际运行；没有证明分词语义质量、有限延迟部署、神经 B 可训或 0.8B 完整模型成功。它是部分 D1 准备件，不是完整 D1/D2 发布。

下一步需要独立现代中英文真实样本及人工金标，固定中文在线政策、最大缓冲／延迟，选择真实 tokenizer 并决定冲突拒收／延迟策略，再接神经 B 消费器。F／展开器从头训练、目标规模等只记录用户选择，本步尚无对应模型实现。

若未来边界或是否施加损失改变了可见前缀，或离线中文标签通过被强制动作进入过去状态，验收应失败；若切片跨 split、改写未继承血缘、代码／词典／源版本漂移而 hash 不报错，也应拒收。当前近重复审计不能穷尽语义改写，不能用夹具测试通过掩盖这一覆盖缺口。
