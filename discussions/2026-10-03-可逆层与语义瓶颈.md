# 可逆层、语义状态与输出重建（2026-10-03）

## 问题、对象、尺度与目标

用户提出：能否借用 normalizing flow 的双向映射，让底部与顶部 Transformer block 成对互逆，底部把字面输入变到较抽象的状态，中部处理语义，顶部反向还原可输出的细粒度状态？这接续[层深与输出阶段](2026-10-02-层深语义与输出阶段.md)。这里的“可逆”指给定完整状态可计算精确逆映射；它不同于 flow matching 中沿概率路径训练速度场，也不同于仅共享或转置权重。

目标不是先证明自然 LLM 已有这种层对，而是检验这种约束能否把“整合语义”和“生成表面形式”构成可训练、低成本的接口。可观察量包括语义编辑成功率、字面细节保留、输出质量、所需状态容量、训练/推理成本，以及是否优于同预算非可逆模型。

## 现有事实与边界

- [Reformer](https://arxiv.org/abs/2001.04451)在 Transformer 中使用可逆残差层，主要为训练时重建激活、减少内存。它证明 Transformer 子计算可以放进可逆结构，不证明反向执行天然会从语义生成语言。
- [Generative Flows with Invertible Attentions](https://arxiv.org/abs/2106.03959)提供带可逆注意力的 flow 组件，但验证场景是图像任务。
- [Discrete Flows](https://arxiv.org/abs/1905.10347)证明离散事件也可构造可逆流，并在字符级语言建模等小任务中实验；不能将其结果外推为现代 LLM 的语义压缩和文本生成已解决。
- [FlowSeq，EMNLP 2019](https://aclanthology.org/D19-1437/)把 flow 用于条件序列生成中的连续 latent 分布，文本解码器仍是另外的概率模块。这提供“可逆 latent + 非可逆 token 输出”的先例，而非底部编码器和顶部解码器严格互逆的先例。
- [NF-CoT，2026 预印本](https://arxiv.org/abs/2606.06447)提出用 normalizing flow 建模连续思想 token，并保留单独的文本 LM head。其性能报告尚未在本项目复核；结构上再次表明“latent 可逆”不要求“词表输出层可逆”。

## 最小形式化和信息约束

取固定长度、连续的 token embedding 状态 h，底部可逆映射 E 把它重排为 (s,r)：s 是希望成为可操作语义的部分，r 保存其余信息。中部更新 s' = U(s, context, goal)，顶部使用共享参数的反向映射得到 h' = E^{-1}(s',r')，再经词表 head 产生输出分布。此模型允许先在同长度内部张量上测试，但词表采样本身不可逆；生成可变长度的新文本还需要长度机制和逐 token 或逐块概率决策。

可用 feature-split 可逆耦合块：y1 = x1 + F(x2)，y2 = x2 + G(y1)；逆向 x2 = y2 - G(y1)，x1 = y1 - F(x2)。F/G 可以包含 Transformer 子模块而不要求各自可逆。整块可逆不保证 s 是语义，也不保证 E^{-1} 在被修改的 s' 上产生自然语言分布。

严格可逆不能把含任意细节的高维输入无损映射为更少的总维度。若中部只操作 s，r 必须保留或从条件分布生成：保留 r 会继续占存储，采样 r' 则放弃逐字精确恢复。例：“甲在周二 15:17 把红钥匙交给乙”与“甲在周三 16:30 把蓝钥匙交给乙”可能有同样的任务级摘要；可逆 E 必须把差异放到 r 或 s 的某处。把乙改成丙后，原 r 也可能仍夹带乙，造成逆变换把旧实体带回输出。必须通过训练和干预测试 s/r 分工。

若顶部严格是底部的逆，且中部不改状态，则整体只是恒等重建。输出新意思来自中部修改 s、新的 r'、额外条件或随机变量；可逆性本身不会创造新内容，也不会让逆映射自动学会文法。

## 因果性与最小可落地实验

先做固定长度的条件改写/问答，不立即追求全自回归预训练。构造含随机姓名、时间、颜色与纠错的短句。底部编码已知输入，可在该输入内部双向交互；输出 token 的预测只能使用已知输入和此前已生成的输出，不能用目标后文预测目标前部。若要逐位置训练同一输入的 next-token loss，底部读入后文会泄漏目标；这两种训练方式需分开定义。

候选原型：两个 feature-split 可逆耦合块 E；仅对预先划定的 s 通道运行小型语义更新块 U；r 通道保留为细节侧带；反向执行 E 的逆，接普通 token head。任务一是原样重建及精确细节追问，任务二是实体纠错后重新生成或回答，任务三是相同语义的多种表达。与参数量、训练量和总 FLOPs 匹配的非可逆 encoder/decoder、无语义瓶颈的可逆模型比较。

关键干预：固定 r、替换 s 中的“乙→丙”，检验输出是否只改实体；固定 s、替换 r 中的表面形式，检验时间、颜色、文风是否按预期变化。若语义编辑不随 s 改变，或语义大量藏在 r 中，说明所谓分工未形成。另测逆向重建误差、编辑后输出合法性、内存与延迟。精确重建率高只证明保真，不证明抽象或泛化。

## 暂定结论、失败条件与下一步

可逆 Transformer 是可实现的组件；“底部 E、顶部 E 的逆、中部处理语义”也是明确可测试的架构假设。现有论文不证明它比普通 encoder/decoder 更适合语言，亦不证明可逆性会自发形成语义瓶颈。其潜在价值是让高层只处理 s，同时保留 r 以恢复需要的细节；其代价是 r 的存储、逆向计算、编辑后越出训练分布，以及仍需解决离散/变长/因果输出。

若成本匹配后性能不优于非可逆基线，或 r 不可避免地承载大部分语义，可逆性不应成为架构硬约束。反过来，若在新组合的语义编辑上 s/r 干预稳定分离，且高层处理更少状态后有净成本收益，再研究动态长度、模块池和自回归生成。

未决：用户说的“底层和顶层对应”是要求严格共享逆参数，还是仅希望正反方向的对称归纳偏置？首要目标是训练内存、少算高层、可控语义编辑，还是生成质量？这些不影响上述最小可逆性测试，但决定下一阶段的系统设计。
