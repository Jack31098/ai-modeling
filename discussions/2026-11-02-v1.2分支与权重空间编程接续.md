## 术语与设计变化

权重空间编程指根据任务规格直接分析、构造或编辑网络权重；应区分已知规则的网络编译、已有网络的局部故障修复，以及新的开放语义能力获得。无梯度是更新方式，不能单凭它推导无数据、无反馈或低计算成本。

v1.2 对现有路线最重要的修订是：参考规约可长期作为主要训练结构，不再以冷启动时先探索优胜路径为前提。B 的离散控制有直接监督，组合器、展开器、F 和相关 A/D 在实际执行路径上联合适配；连续 latent、子结果及 RETURN 由学生计算，不用教师向量或标准结果替换。

最新研究记录进一步要求先获得可信状态观测、因果干预与知识增量，效率暂不作为继续研究的硬门槛。单级与多级都保留比较；额外可读状态的价值与分层组织本身的价值分别验收。

## 已有证据及其边界

以下项目内实验数字来自分支研究记录，未在本轮读取原 ZIP 或重放数值函数：

- 有限规则解析器在归档原型方向和随机编码条件下均为 1000/1000。它支持有限词汇和文法，句末输出父字段，没有通用 B⁺ 边界控制或真正 B⁻ 的子结果回流闭环。
- 27B 词表示压到 1024 维的低秩结果，在小型探针上未普遍优于随机投影；不能把保留较多能量等同于学生知识迁移成功。
- 新字段消费者能够使用构造出的父态，不代表原 Qwen F 能直接消费该编码；同宽也不保证坐标或缓存接口兼容。

外部原文的 Qwen3.5-0.8B 改善主要定位于解除推理循环；Gemma 270M 的对应尝试未获得明确能力提升。这支持局部修复作为研究方向，尚不足以证明可普遍添加缺失语义能力，也不足以证明此事不可能。

对反馈预算需补充明确：作者所谓一次 forward pass 可包含批量样本；Qwen 实验平均每次约 64 条序列，允许最多 512 个题目的生成，或最多 1024 段文本的读取。不能将“50 次反馈”转述为只用 50 道题、50 个 token 前向或几乎没有验证成本。具体预算口径仍以其 harness 和日志为准。

## 本轮推论、最小例子与失败条件

随机编码同样通过有限文法测试，说明当前成功不需要预训练词向量的语义结构来解释；它是有价值的协议／规则编译基线。该负对照不排除预训练表示在更开放词汇和组合任务上产生增量，后者需要新的受控比较。

最小下一步可以固定父计划“总预算 10”：第一 child 的实际消耗分别为 3 或 7，父 scope 接收真实 RETURN 后，第二 child 可用预算应分别为 7 或 3。分别记录状态前后、读取来源与调用；屏蔽或替换 RETURN，检查行为是否按协议改变。这个例子只验证结果消费与状态更新，不冒充自然语言理解。

再在相同可用信息下比较单级状态表与两级调用，保留同容量及自然配置两种口径。若仅增加明细访问就获得全部收益，应归因于信息可用性；若相同信息下分层仍带来未见嵌套组合或错误定位的增量，才进一步归因于组织方式。

反例包括：父程序忽略实际 RETURN 而使用预写答案；只用强探针而主任务不读状态；教师标准结果提前进入父计划；多级拥有明细而单级被禁止保存等量信息；随机组合均来自构造时同一有限文法却被报告成开放语言泛化。

## 对当前环境与下一步的影响

此前下载的 Qwen3.6-35B-A3B Q8 GGUF 仍可作为后续语言生成／标注候选；它与用于浮点权重分析、直接编辑和小模型训练的实验资产是不同角色。不能因 teacher 权重已下载，就声称本地已具备博客中的权重编辑或学生训练环境。

近期优先少量可检查 episode、事件编译、状态轨迹和 RETURN／读权限干预；先验证学生消费闭环，再扩大 AI 标注。对可学习组合器、词表示迁移和原 Qwen F 接入分别设置增量实验。

未决问题是：开放语言内容怎样获得超过规则基线的泛化；何种状态保留带来真实后续知识增量；多级在等信息条件下有什么价值；以及原模型接口需多少适配。上述问题均未由本次阅读或已有有限实验解决。
