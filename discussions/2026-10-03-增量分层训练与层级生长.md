# 增量分层训练与层级生长（2026-10-03）

## 用户修正、目标与研究顺序

用户指出，前轮固定 token 分块只是在形式上变粗，不等于语义粒度；对照 BLT，按内容分配计算更有依据。把完整模型预设为 E/C/D，再联合预训练，没有交代如何持续细化和扩展。当前需要的是增量路径：先训练一层，训练后再加下一层；每一步能工作、能验证，允许暂时不最优。多层玻尔兹曼机/DBN 的逐层学习提供方法论启发。

据此不再把“先训练固定块 E/C/D”列为项目下一步优先路线。前文[统一自回归预训练](2026-10-03-统一自回归预训练与读写分工.md)保留合法损失与因果边界的分析，不能当作已经回答了增量生长。当前优先定义一个可重复的加层操作，再独立验证新层是否能低频更新。没有实现或训练结果。

## 术语与待验证假设

- **一层起点**：embedding、一个因果序列变换层及 token 输出头组成的完整小语言模型；不是已具备通用能力的一层大模型。
- **参数层**：使用一组新权重的变换。增加深度不自动增加语义层级。
- **粒度层**：在下层的一部分更新事件上执行，维护持续多个下层事件的状态。一次粗状态更新可以服务多个细粒度预测。
- **树状目标的工作解释**：父状态组织多个子状态，较粗状态可以条件化下层输出；叶端仍输出线性文本。不是词表 softmax 的编码树或候选 token 搜索树。
- **阶段验收**：每次新增都有完整的 token 输出损失，能单独比较预测质量、成本及旧能力；关闭新增部分能回到此前模型。
- **用户偏好**：可行、可接续优先于一次确定最优终局。这个偏好不证明逐层训练会必然长出抽象或语义树。

输入的层级组织、不同层的更新频率，以及先生成父计划再展开子文本，是三个相关但不同的能力。后者不能由 bottom-up 压缩直接推导。

## 已核查的研究与边界

### BLT：内容相关粒度，有证据；不直接保证语义层级

[BLT 原论文 §2.3–2.4](https://arxiv.org/html/2412.09871v1#S2.SS3)使用单独训练的小型字节自回归模型，根据下一字节预测分布的熵设置动态 patch。它从原始字节出发，不是先经 BPE 分词，再把 token 固定归组。边界反映可预测性，不能默认等于概念或句子的边界。

因此固定分组不应被命名为“语义粒度”，内容相关分配更贴近本项目目标。但“在任何设置下必然不如 BLT”仍超出现有证据，需预算匹配的比较。熵可提供分层开始时的信号，不能保证每个更高层都能照搬同一个阈值。

### E/C/D 可以递归细化，但这尚不回答逐层生长

[H-Net §2.1](https://arxiv.org/html/2507.07955v1#S2.SS1)明确允许把 main network 递归替换成另一个 H-Net；两级包含 E0、E1、M、D1、D0，并研究了动态边界和多级模型。所以三种职责不是只能有三个 Transformer block，结构上可以细分。

它按预设级数端到端训练，没有验证“一级训练好再新增一级”的课程；也没有验证先产生未来父计划再展开输出树。生成时外层细粒度 encoder/router 仍运行。本项目不能把递归结构先例当成已获得增量训练路线。

### 增量加入新层：现代语言模型有直接先例

[LLaMA Pro](https://arxiv.org/html/2401.02415v1)冻结原有 Transformer 层，插入输出投影为零、初始为恒等映射的新残差块，继续预训练新增部分。这支持保留已有函数、单独学习新层的启动机制；实验不是从一层逐级长出语义树。

[Stacking Your Transformers](https://arxiv.org/html/2405.15319v1)验证先训练较浅语言模型、再堆叠复制层并继续自回归训练；不证明原层永久冻结或新层自动改变输入粒度。当前最有用的是前者的保留函数初始化，堆叠仅提供补充证据。

### DBN：借用明确的阶段接口，不迁移其理论保证

[Hinton、Osindero、Teh 2006，§4–5](https://www.cs.toronto.edu/~hinton/absps/fastnc.pdf)逐层训练，并在特定模型/理想学习条件下分析生成似然改善；实际使用 contrastive divergence 时原文明确取消保证，之后还做 up-down 校正。

它支持先获得可用下层映射、将隐状态作为上层训练数据的思路。这个生成模型的条件不自动适用于 Transformer、因果文本与稀疏路由；不能声称照此逐层增长就有单调性能保证。

## 第一项增量实验：一层到两层

### 起点：一个完整的小语言模型

h_t = F1(x_<=t)，p1(x_(t+1)) = softmax(O h_t)。

先训练 F1 与输出头 O，使用普通语料的全 token 下一词交叉熵。不预先要求 F1 成为语法层，也不要求它完成所有长程理解；首先获得稳定、可评价的基线。

### 加一层：初始预测保持旧模型

冻结 F1 与 O，新增 F2 及回传投影 P：

u_t = F2(已知下层状态与历史)，
p2(x_(t+1)) = softmax(O (h_t + P u_t))。

P 初始化为零，F2 采用正常或已有权重初始化；不把所有新权重都置零。于是加入瞬间 p2 = p1。这个等式仅说明初始化保持旧函数，不保证之后训练、验证集质量或成本单调改善。

继续同一个 token 交叉熵，只训练 F2、P。固定输出头仍可将梯度传回新增部分。P 为零时 F2 在首步通常没有来自该分支的梯度，P 先得到更新，之后 F2 可开始学习；需要确认这条梯度路径，不能把零初始化包装成无条件优化保证。

F2 可以先是普通因果 Transformer 变换，每个位置执行。此时新增层只需要补充有助于预测的信息，没有“必须把若干 token 归为语义节点”的先验目标。可保存新增前检查点，并显式保持关闭 P 的旧路径。

### 第一阶段判断

比较两层与已训练的一层模型，检查长距离关系、名称、数值和否定条件的预测，确认新增模块被实际使用。还应有同训练预算继续训练旧模型等对照，以排除纯额外训练量解释。

若新增层无收益，先检查数据、接口和旧表征信息缺失，而不是直接加第三层。即使有收益，这一步只证明增深能继续学习，没有证明稀疏、粗粒度或树状输出。

## 第二项相邻实验：仅给新增层增加低频更新

在 F2 已学会工作的基础上，再增加一个便宜的门 g_t 及累计状态 a_t。a_t 收集自上次更新后已经发生的下层事件，不读取未来：

u_t = F2(u_(previous), a_t)，若 g_t = UPDATE；
u_t = u_(previous)，若 g_t = COPY。

最初让每个位置都 UPDATE，保留已有两层路径。随后用原始 token 交叉熵、与密集两层参照的预测一致性，以及实际更新成本约束训练 F2/门/累计接口。旧 F1 先保持固定，避免同时改变多个未知接口。

门不由固定 token 数定义。它要学习何时继续复用当前粗状态、何时有必要读取累计变化。BLT 的熵可用作开始时的提示或对照，最终仍需用后续预测质量检验。单独设置很强的更新罚项可能让新层总不执行；单独保留 CE 也可能让它总执行。

[Hierarchical Multiscale RNN](https://arxiv.org/abs/1609.01704)提供可学习边界和 UPDATE/COPY/FLUSH 的多时间尺度语言模型先例；把这种机制接到逐层增长后的 Transformer/其他序列层，是本项目的候选组合，没有直接实验保证。

这里还要改变或定义缓存接口：F2 只在事件边界执行时，使用的是事件状态/KV；跳过的下层输入通过 a_t 汇集。不能删掉旧层位置的计算而默认其 KV 语义保持不变。如果仍为所有位置建立昂贵 F2 KV，其成本也必须计入。

软门若同时计算两个分支，只是训练路由，不代表真实省计算。验收必须使用硬执行、完整计入门和累计接口成本，测实际延迟与内存，并对照同质量的密集模型。

## 可重复到第三层的接口

如果 F2 的少量更新确实能服务多个下层事件，F2 的更新事件就成为 F3 的输入流。F3 再执行相同的操作：保留此前预测 → 学习新增状态及回传接口 → 验证有用 → 尝试低频更新。

第三层仍用最终原始 token 的预测损失训练，梯度通过固定的相邻映射到新增接口；不要求人工定义“第二层语义标签”。如果相邻固定映射不能利用新状态，可以先只开放一个小 adapter，必要时再对相邻层做受控校正。用户的分阶段原则不必被理解为所有旧权重永久不可改变。

这样先形成由细事件到粗事件的多时间尺度组织；若各级边界嵌套，累计区间可形成父子关系。原始细节与子事件可保留引用供回访，但回访、存储和缓存管理成本也要算入。

这条重复操作给持续细化一个候选接口，比先规定 E1/E2/E3 各自语义更明确；它尚不保证每增加一级都更抽象、更高效或适合继续增加下一层。

## 输出树仍需要单独定义的一小步

当前公式中，粗状态通过 P 影响细粒度预测，能在保持某个状态的多个步骤中指导输出。但它首先得到的是稀疏状态更新与条件接口，不能直接称为已学会“父节点生成子节点”的语义输出树。

若用户的目标是先产生未来段落/步骤的父计划，再展开多个子状态，新增一级还要学习：

1. 如何只从已知历史产生这个父状态或父状态分布。
2. 如何将它作为既有子层的条件，并决定何时结束当前展开。
3. 实际产生的子内容如何影响下一次父状态更新。

可以先检验已有 F2 状态是否能持续条件化 F1 的一段输出；若没有因果控制收益，先不加自由树路由。若采用“编码完整未来子段形成父向量”的训练数据，该父向量只能作为训练期 posterior/教师目标，仍须训练部署期 prior，不能直接喂回 token 预测并声称纯 AR 无泄漏。

同样，这条增量起点尚未实现最初提出的输入完全省输出层、输出完全省输入层。应保留这些目标，逐项观察生长出的层是否真的具有可分离职责；不在第一步提前绑定读写互逆。

## 反例、停止条件与当前结论

- 新层最终只产生无意义的零影响，或提升来自更长训练：尚无新增能力证据。
- 新层在困难任务上几乎每个下层事件都需更新：该层可能有深度收益，但未获得粗粒度稀疏收益。
- 少更新只在模板/常见词上成功，随机细节和跨段条件失效：不能宣称语义压缩成功。
- 下层冻结后丢失上层所需信息：上层难以补救，需要保留输入/子状态通道或局部校正；纯贪心冻结路线可能失败。
- 层级只提高预测，却不能条件化较长输出或支持模式切换：尚未得到用户要求的输出树。
- 每次新增需要重训几乎整个系统、旧路径不能保留：当前增量接口没有实现分阶段目标。

当前判断：保留函数地加入新层已有可用先例；把新层训练成低频状态、再将其事件流交给更高层，是有明确监督和接口的候选小步。树状语义读写尚无完整可行性证明，不作承诺。研究顺序偏好改为首先检验一层到两层的学习，再仅在这一层上检验更新频率；固定块 E/C/D 退为因果分析与对照。
