## 2. 对象、尺度与监督的含义

首轮只讨论一个 B 尺度：底层 token 的有序连续输入 → B⁺ 完成单元 → F 消费历史并产生计划 → B⁻ 逐孩子展开 → 底层文字输出及实际结果返回。更高尺度暂不引入。

须区分三种 embedding 相关用法：

1. 输入表 E_in[x]：已训练好的底层输入向量；作为输入或初始化，不自动决定组合后的父态。
2. 底层输出：可用固定 E_out 作为词表读出，监督 token ID；也可额外回归目标 E_out[y]。这两种损失不等价。
3. 整个规约单元的向量：若确实有独立、固定且可对齐的整词／单元表，可在其覆盖范围内提供局部直接监督；子词表并不自动包含每个合并单元的行向量，任意词组或句子也不一定有现成目标。

已向用户询问“输出 embedding label”主要指底层 token、整个规约单元还是两者；本记录暂保留分支，不把任何解释倒写成确认事实。输入／输出表是否相同、绑定、同维、冻结，也待选型。

中间 latent 没有唯一向量答案不阻止训练。只要真实路径可微，末端文字／任务损失即可训练组合器、F、展开器；边界及结束动作另受离散监督。固定两端表不能唯一确定中间坐标，相邻模块可对某些可逆坐标变换相互补偿。

## 3. B⁺ 的首尺度候选设计

以下为提议，尚未被实验验证或由用户逐项采纳。

### 3.1 状态与输入

- 当前到达的底层表示 u_t：来自 E_in，若路径包含 A，则使用 A 的实际输出。
- 当前开放单元的有序缓冲、增量工作态 h、单元内位置／有效长度。
- 合法的局部前缀条件 c；不得先执行准备省去的完整 F 再作边界判断。
- 实际收到的结束／暂停事件；参考边界和未来全文长度不属于输入。
- 若允许延迟关闭，保存有界 pending 后缀、必要快照和实际形成时间。

有序更新的接口可写为 h_t = U_+(h_{t-1}, u_t, position_t, c_t)。首个候选可以是门控递归块；有界因果 attention 可作后续对照。无位置的均值或求和不能区分同词多重集的不同顺序，不宜作为唯一内容核。

### 3.2 控制与完成读出

控制头从当前合法状态预测继续或关闭。先计算预测及边界损失，再由训练驱动器决定执行参考动作还是学生动作。关闭时通过 R_+ 形成父态 z_j，并记录该状态真正可用的事件时刻；清空或重置已消费单元，pending 留给后续单元。

边界 label 还必须编译到真实 tokenizer 和决策时刻。若“看到分隔符才确定前一词结束”，不能把分隔符错误算入前词，也不能回填到过去关闭。可以采用有界延迟的 CLOSE(k)：本次已读到 t，关闭缓冲内截至 k 的前缀，保留 k+1…t；依赖后文才得知的离线边界不能直接强制成早期动作。

若通过递归 h 的快照读出已关闭前缀，后缀必须在新单元初态下合法重算；不能复用含前单元历史的旧 h_t 冒充独立后缀状态。延迟预算、合法 k 范围和容量强制关闭需单独配置。强制事件不伪装成可学习决策。

### 3.3 梯度与完成条件

边界损失训练控制头及其共享上游；文字／任务损失沿 F、B⁻、输出读出回到 B⁺ 的连续计算。任务梯度不会自动穿过整数切分位置变成控制梯度。主路径不需要父态向量金标；可选整词目标或事实探针必须标明覆盖范围和权重。

验收同时看边界、顺序／角色／否定／数字保真、父态实际消费与有界因果性。仅边界 F1 高不足以验收整个 B⁺。

## 4. B⁻ 的配套设计边界

B⁻ 要实现父条件驱动的自回归展开，不假设它是 B⁺ 的数学逆。

候选接口：F 产生当前合法父计划 p → 初始化本次调用的工作态 → 根据计划和已完成结果产生下一个 child 条件 → 下层执行并返回实际结果 r → 更新工作态 → 判断继续还是结束 → 完成后形成 result 并交还上层。

父计划与实际结果分开；不能在生成前放入完整目标编码所得的 z。叶端产生词表预测，较高层产生下级调用条件。输出单元结束、父 scope 结束、全文 EOS 分别定义。只有当前边界 label 时，可按既定遍历协议编译局部继续／结束监督；不能据此声称已经覆盖查询、缺失、Lookback 等全部能力。

特别注意两个时序：

- 重建模式允许编码已经完整看到的输入单元，然后展开它，指标称重建。
- 续写模式下，当前单元的计划必须来自先前合法历史；完成该单元后的 result 才能进入后续 F 历史。不能先编码当前目标单元再据此预测它，借用重建成功证明生成。

生成中的 result 可由逐孩子工作态直接形成；无需默认将全部自产文字重新跑完整输入路径。B⁺ 与 B⁻ 的内容更新可考虑共享，但共享比例、计划／结果接口和控制头是否分开仍待比较，不因维度相同就假定兼容。

## 5. 联合训练 baseline

联合训练并非数学上唯一办法：局部编码／展开预训练、分阶段训练、交替优化都可行。但在没有固定父态金标、下游接口需共同适配时，联合训练是当前选定的基线。

建议起点：执行稳定参考边界，同时训练学生动作预测；B⁺、F、B⁻及相关适配／读出在实际路径上接受任务梯度。输入／输出表先固定可作为控制变量，但这属于建议，不是用户已经确认的冻结配置。

首个损失候选：文字 token CE + B⁺ 边界监督 + B⁻ 继续／结束监督；embedding 回归或事实辅助项可另加对照，先不作为唯一主目标。各项按 token／有效事件分别归一化。

固定输出表可通过适配后的 hidden 与各词表行计算 logits，再以正确 token ID 计算 CE。若使用 MSE 回归目标 embedding，多种合法续文时最优预测可能接近条件均值，并不等于任一合法词；因此需与词表分类、自主输出一起评价。若有整词固定目标，应另测它是否让带上下文的父态过度丢失区别。

之后分别降低结构 forcing 和文字 forcing。偏离参考分片后重新对齐监督或结束片段。保留参考路径、学生动作＋文字 forcing、完全自主三种报告；前者条件文字损失不称普通纯文本 PPL。

## 6. 参数空间重编程的具体介入点

本节是待测假设，不是已经存在的加速结果。先把 baseline 跑通，再以相同结构／状态容量分叉。

### 6.1 构造有序暂存与读出起点

对最多 K 个孩子的有限单元，可直接构造有序槽位／移位、计数和边界读出的部分权重。若每孩子原维 d，完整保留 K 个向量需要相应容量；固定父宽度不能无条件无损容纳任意长度和精度。

一种有限预算候选是每孩子投影到 q 维，按顺序写入 K 个槽位，再附有效长度；需明确 Kq 与父态容量关系和投影损失。给同一网络构造这些初值并继续梯度学习，与同结构普通初始化比较，才回答初始化是否加速。改成更宽网络取得收益，不能全归因于权重编程。

这验证的是顺序／暂存的已有机制能否减少冷启动负担，不等于直接写出了通用语义压缩器。若原执行器已用普通代码实现计数与缓冲，再把它写进权重本身未必有收益。

### 6.2 表示接口初始化

可在已选定的 E_in/E_out 上构造小范围原型识别，或用训练集拟合接口投影。须区分：已知规则直接填矩阵；最小二乘／SVD 等数据拟合；LLM 观察权重后直接提出编辑。无梯度拟合不等于无数据，也不能把所有常规初始化都称为 LLM 参数空间重编程。

已有有限解析器在随机 token 编码下也通过，说明识别身份与利用预训练语义是不同问题。表示初始化需要随机编码／投影对照和训练后任务评价。

### 6.3 同一训练检查点的局部编辑

出现稳定故障后，从同一检查点分叉。向编辑者提供模块规格、权重、少量训练侧状态轨迹及限定反馈，只允许修改约定的小模块，例如某类提前停止、结果回流或数字保真问题。与不编辑、简单规则修改、同预算局部梯度适配比较；随后继续同样的训练。

编辑不能写入评测答案，不能替换孩子真实结果，也不能用测试集选择编辑。若连故障位于控制还是内容都未定位，先收集状态与因果干预，避免盲改完整 F。

### 6.4 加速的判据

比较达到相同独立质量门槛的总成本，至少分开报告训练 token、梯度步数、GPU 时间、编辑模型推理、反馈前向、权重分析和失败尝试。多随机种子、相同训练数据和自主运行指标；一次性构造成本与跨多次训练的摊销另列。

少训练几步而总耗时更高，只能称步数减少。训练 loss 下降更快、边界模仿提高或局部探针改善，也不能替代相同自然语言／协议／自主质量门槛。

## 7. 最小例子与反例

- “甲给乙73”与“乙给甲37”：边界可以相同，但顺序、角色和数字必须在真实任务中区分；均值聚合可作为负对照。
- “研究生命起源”：保留离线与有界 FMM 的不同边界，不把因果／有界通过当作分词金标。
- 相同输入前缀搭配不同未到达后文：已提交父态及此前自主决策不应提前变化。
- 相同父计划，第一个 child 实际返回成功或失败：后续行为应依据实际返回变化。
- 多种合法下一词：embedding MSE 可能输出平均向量，需测词表选择与实际文字质量。
- 修改／屏蔽父态或 F：若任务不受影响，要排查局部 decoder、原文旁路或监督泄漏，不能凭训练 loss 宣布中央路径有效。
