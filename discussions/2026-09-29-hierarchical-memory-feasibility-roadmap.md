## 1. 对象、目标与可观察量

最后的 vision 可拆为三个独立假设：

1. **记忆组织**：模型能主动读写、纠正、合并、展开和遗忘上下文，以有限的活动记忆支持长时间任务。
2. **潜在空间推理**：模型可以反复更新连续状态，在输出文字之前完成一部分推理。
3. **计算调度**：模型按内容和难度选择计算深度、分块粒度、访问层级及停止时机。

三者可以结合，但任意一项有效都不能推出整套系统有净收益。“可写”“latent”“层次化”“动态路由”需要分别做消融。

- **对象与尺度**：第一阶段限于语言和离散环境中的多轮状态跟踪、推理和经验复用；暂不把机器人感知控制纳入同一验证。
- **能力目标**：保持基础语言能力；经历更新后更可靠地完成未来任务；在长历史下控制活动内存和实际计算成本。
- **活动记忆**：当前可被计算核心访问的有限状态，不等同于全部历史。原始证据可留在外部存档；读取它也计入成本。
- **慢参数**：部署时固定的主网络参数。训练阶段可更新；如果另加 TTT 式快速权重，应明确那部分参数在推理时变化。
- **可观察量**：任务成功率、状态纠错与依赖更新准确率、未见组合与新规则迁移、精确细节回忆、错误自信、内存字节数、端到端延迟及总计算量。训练成本另记。

## 2. 暂定判断

**建议投入验证。主动维护可复用记忆具有技术依据和应用价值；直接把全部 KV 改为任意读写的层次树、允许自由跨层 goto，则缺乏足够证据支持作为第一步。**

可构造原型与证明优于现有架构是不同门槛。真正值得检验的主张是：在同等证据访问权限和预算下，学到的记忆更新能否比保留原文、检索、文本摘要和固定递归状态，更好地兼顾长期正确性、经验迁移与成本。

个人研究偏好：优先关注“事实被纠正后，能否同步修订依赖它的推断与计划”和“经验能否变成未来任务可用的规则”。这比仅演示更短的上下文，更能检验主动知识组织的价值。

## 3. 已有研究支持哪些组件

以下只引用原始论文；列举不构成对全部相关工作的穷尽。

- **可读写记忆是已有技术方向**：[NTM](https://arxiv.org/abs/1410.5401) 把神经控制器与可寻址外部记忆结合；[RMT](https://arxiv.org/abs/2207.06881) 用 memory tokens 跨片段传递状态。因此研究价值需要落在可扩展训练、可靠性或效率的具体改进上。
- **latent 递归具有可行性证据**：[Coconut](https://arxiv.org/abs/2412.06769) 将最后隐藏状态作为下一步输入嵌入，仍经过模型计算；其论文结果依赖任务，并非全面胜过文字 CoT。[Scaling up Test-Time Compute with Latent Reasoning / Huginn](https://arxiv.org/abs/2502.05171) 训练具有循环深度的语言模型，支持沿该方向扩大规模的可能性。它们没有证明给任意现成 LLM 加回路就能稳定增益。
- **多尺度记忆和动态粒度有实现先例**：[MELODI](https://arxiv.org/abs/2410.03156) 联合短期与长期压缩记忆；[H-Net](https://arxiv.org/abs/2507.07955) 学习动态分块及层次表示。它们支持组件可训练，不证明层级必然对应人理解的词、句子、概念。
- **选择性计算可以训练**：[Mixture-of-Depths](https://arxiv.org/abs/2404.02258) 在固定计算预算下选择参与某层计算的 token。其有界形状和路由约束提示：硬件友好的动态性比完全自由控制流更适合作为起点。
- **主动记忆整理不必先采用连续 latent**：[MEM1](https://arxiv.org/abs/2506.15841) 学习整合文本内部状态；[UMA](https://arxiv.org/abs/2602.18493) 在不知道未来具体问题时维护结构化 Memory Bank，并用未来问答回报训练维护策略。这些应成为强基线。
- **另一类状态适应方案**：[TTT](https://arxiv.org/abs/2407.04620) 在测试时通过自监督更新作为隐藏状态的小模型；[Titans](https://arxiv.org/abs/2501.00663) 探索测试时更新的神经记忆。这条路线适合纳入候选，但精确事件存取、可解释纠错和删除需要另外验证。

补充线索：[ActiveMem](https://arxiv.org/abs/2609.33244) 的 2026-09-27 预印本摘要也提出依赖感知的记忆树与学习扩展、检索、剪枝策略。本次只核查摘要，不将标题中的 latent tree 视为已经实现模型内部跨层隐藏状态树，也不依赖其性能主张作出判断。[关于经验复用的研究](https://arxiv.org/abs/2604.27003) 在其测试环境中发现，外部记忆仍面临检索竞争和负迁移；此结果提醒我们不能把固定慢参数等同于消除遗忘。

## 4. 对前一段讨论的技术修订

### 4.1 网络深度和抽象粒度需要分别建模

普通 Transformer 的高层表示可能更适合某些抽象任务，但不能据此把第若干层直接当成“句子层”或“概念层”。层次化分块需要明确的聚合、读取、跨尺度通信和训练目标。

一句话也不必只对应一个向量。关系、否定、时间、例外和精确数字可能需要多个状态或原文引用。树可作为粗到细访问的索引；事实之间存在共享依赖，未必适合强制组织成唯一父节点的树。实现上可以先采用扁平槽位，再添加索引和稀疏依赖边。

### 4.2 KV cache 不应自动等同于可变知识库

标准因果 KV cache 保存的是既往计算的结果。若后续状态已使用旧事实，直接改写较早的 K/V 不会自动重算这些后续状态。例如“钥匙在 Bob 手里”已产生“先找 Bob”的计划，改写持有人后还需要修订计划。

技术推论：可以训练一个明确支持可变记忆的模型，但必须定义什么是当前事实、哪些缓存失效、哪些推断依赖被改写的内容。建议将权威记忆状态与计算缓存分开，各层通过学习到的投影读取记忆；KV 仍可作为可丢弃的加速缓存。

### 4.3 压缩只能相对于未来任务保留充分信息

有限精度的 b 比特状态只有至多 2^b 种取值。若历史包含超过该容量的任意独立细节，又要求未来能精确回答任意历史问题，就必然存在不可区分的历史。改变为连续向量或多级树不能消除这个限制。

例：将“周二 15:17，红色钥匙扣”压成“完成交接”，可以保留交接事件，却不能保证还原时间与颜色。若必须回答这些问题，应保留原始来源或承担不可恢复的损失。因此“遗忘”先定义为移出活动记忆；不可逆删除应作为独立任务权衡。

### 4.4 递归和路由并不自动带来效率与正确性

重复计算可以细化状态，也可以重复错误。应检验增加迭代是否改善困难样本、停止机制是否可靠、训练范围外的迭代是否稳定。[TRM](https://arxiv.org/abs/2510.04871) 等小模型在结构化任务上的成绩，不能直接外推为通用 LLM 的能力或成本结论。

latent 步数更少也可能需要昂贵的整网前向。跳层减少 FLOPs 可能因路由、散乱访存、重取证据及批处理效率下降而没有延迟收益。输入加工、反复整理记忆、解码和外存访问都应计费。

### 4.5 固定参数与学习并不矛盾，但改写状态不是学习效果的充分证据

传统 ICL 已是在固定主参数下根据上下文适应任务，参见 [Language Models are Few-Shot Learners](https://arxiv.org/abs/2005.14165)。主动读写提供更丰富的状态更新方式，不能据此断言“这才是真正学习”。需要证明读过经历后，在未见实例、规则组合或任务上表现改善；只复述保存的答案不够。

NTM、图灵机和栈的类比可帮助提出接口，但理论计算能力不能推出可训练性、泛化或效率。append/pop 加全历史注意力也不能直接归类为普通下推自动机。脑科学类比在本项目中只作为灵感。

## 5. 候选实现及适用条件

1. **文本/结构化记忆 + 原文检索**：作为诊断和对照基线。便于查看、纠错、保留来源和调用精确工具；代价是序列化与重新编码。用户已有更深入的 MASA 设计，应从其关键机制继续，latent 路线的比较也应覆盖现有 latent memory 方案。
2. **固定容量 latent memory + 固定调度的递归核心**：最接近核心模型研究的起点。连续状态可能承载无需逐字表达的中间计算；风险是读写接口难训练、状态不可解释及反复压缩误差。
3. **TTT/快速权重**：可比较其对流式分布适应与规则提取的效果。需要区分统计适应和可精确引用的事件记忆，可以与显式记忆组合。
4. **长上下文或稀疏注意力 + 检索**：如果任务以少量精确历史查询为主、很少需要持续状态更新，这些方案可能更划算。

**当前架构建议（假设）**：近期原文缓冲和可回查证据存档；有限的可写工作槽位；可选的事件/规则摘要；共享递归计算核心；明确的读写与提交接口；文字/动作解码器。通过来源指针和版本关系支持必要的展开、纠错和依赖失效。高层记忆形态由实验选择，不预设必须是一棵树。

最简抽象为 `M[t+1] = U_theta(M[t], observation, goal)`，回答或行动由当前记忆和必要证据共同决定。theta 在部署时固定，M 更新；后续引入递归推理状态 z，并检验它是否值得与长期记忆分开。存储、推理、计算调度先分别建立能力，再联合训练。

## 6. Roadmap：每一步有进入下一阶段的条件

### 阶段 0：确定任务与比较协议

先做能生成正确答案的离散事件环境，覆盖实体、关系、时间、纠错、例外规则及目标变化。形成记忆时隐藏未来具体问题，再从同一记忆分支提出不同问题。混合可压缩的重复模式和无法预测的随机细节，避免数据天然偏袒摘要。

最小例子：先报告 Alice 把钥匙给 Bob；随后明确纠正“原报告中的收件人应为 Carol”，不是再次转交。系统需修正当前事实和依赖它的计划，同时可回答“原报告写了谁”。之后更换人物、规则和任务，检验迁移。

基线包括完整上下文、原文检索、文本/结构化可编辑记忆、固定压缩或递归 memory tokens。控制训练数据、模型规模及外部证据权限，报告质量—总成本曲线；不能只比较相同 latent/token 数。若某方案使用更多训练，应同时报告。

### 阶段 1：验证主动组织记忆本身的价值

用可观察的槽位或结构化记录实现新增、修订、失效、提炼规则。早期利用环境真值或操作示范监督，随后以多种未来任务表现训练维护策略。

**通过条件**：纠错能影响依赖推断；新问题与新组合上有收益；在有限记忆下优于简单追加和摘要。冻结写入、清空或打乱记忆的因果干预应消除相应收益，排除模型背答案或读取泄漏信息。

### 阶段 2：验证 latent 表示的额外收益

在可训练的开放权重语言模型上加入固定槽数、固定读写时点的记忆接口，可用 memory tokens 或跨注意力。先训练读写模块/adapter，必要时逐步解冻网络；冻结底座的失败只说明接口可能不匹配，不能单独否定方向。

用未来预测、任务答案和执行结果训练。teacher 的文本推理或操作轨迹可以辅助课程学习，不必把 teacher 的隐藏向量或“一句话一个向量”当作唯一目标。

**通过条件**：相对强文本记忆，在匹配成本下取得稳定收益，或匹配质量下降低总成本；保持基础能力。若没有收益，保留显式记忆路线。

### 阶段 3：加入 latent 递归推理

先固定迭代次数、共享计算核心；验证后才学停止策略。分别比较无递归、有文字 CoT、有 latent 递归，确保同等证据条件且计入全部前向成本。

**通过条件**：增加计算确实改善一部分困难任务，且总体质量—成本曲线优于已有方案。观察错误放大、循环及训练深度之外的失稳；不能把增加推理步数视为无上限有效。

### 阶段 4：加入层次压缩和选择性访问

先从工作记忆与归档记忆两个尺度开始，学习何时合并、访问原文、展开和修订。训练同时覆盖概括、关系推断、精确数字及来源追问。优先采用少量可批处理的块大小和有限路由选项。

**通过条件**：历史增长时活动内存受控，长期错误不持续累积，精确查询能回查；计入维护与检索后的延迟仍有净收益。若树不适合共享依赖，换索引或图结构；若层次化收益不及复杂性，保留扁平槽位。

### 阶段 5：联合学习策略并扩大任务和模型

学习读、写、合并、检索、计算与停止策略；先示范/课程学习，再用跨多轮任务回报和资源约束训练。奖励未来多个可能问题的表现，避免只为眼前答案删除重要信息。训练时可见的信息和部署时保持一致。

完成模块消融后，才投入更大规模的继续预训练或从头训练，研究中层入口、跨层回路等更自由的计算图。语言任务通过后扩展到长程代码任务、研究任务等；多模态与机器人还需要动作条件预测和闭环控制的独立验证。

**通过条件**：现实任务上保留净收益与可纠错性，训练和推理成本可接受。固定慢参数部署只限制部署期，不妨碍训练期充分适配新架构。

## 7. 失败条件与决策原则

- 如果只能在已知问题的摘要任务上胜出，尚未证明对未知未来问题有良好记忆组织。
- 如果读取原文后才有效，需区分检索质量的贡献和 latent 记忆本身的贡献；原文读取成本不能省略。
- 如果改写事实后计划仍基于旧事实，读写接口尚未解决一致性问题。
- 如果所有收益均来自更大底座、更多训练或更多总计算，不能声称结构本身更有效率。
- 如果显式记忆足以达到目标，选择显式记忆；如果递归、层次化或自由路由没有独立收益，去掉对应部分。
- 如果所有原始信息都必须永久留在活动内存才能保持任务质量，应重新界定可压缩的任务分布及预算目标。

## 8. 未决问题与下一步

尚未确定：目标优先级是通用推理、长期 agent 还是流式适应；实际训练资源；未来查询分布；允许的误差与外存预算；应保存哪些依赖；摘要如何避免把错误巩固为规则；跨任务经验何时引起负迁移。

修订后的下一步：明确 MASA 思想状态到内容输出的直接通道，验证在原文和取证范围相同的条件下，latent 状态能否承担推理结果存储与修订；同时检验未知未来任务和依赖更新。实验仍需检索、文本与现有 latent memory 基线，但不再把普通文本记忆当作本项目尚未提出的研究起点。
