## 问题与定义

用户要求下载可推理 H-Net，观察不同层级码率；随后要求构造信息冗余不同的文本，并比较句子粒度、外围遗忘和 B⁺/B⁻／耦合结构。继续依据 [v1.2 固定版本](https://github.com/Jack31098/ai-modeling/blob/1ff300bfbb9a8ebb7bee242a0cbc37848fa6e190/path_control_pretraining_part1_v1.2.md)，不将口头描述升级为新约束。

本轮“码率”明确为序列节点率：原文 L₀ 字节，第一层 L₁ 节点，第二层 L₂ 节点；分别报告 L₁/L₀、L₂/L₀ 和逆向压缩比。它不是熵编码后的 bits/byte，连续向量有宽度与精度成本，不能把少节点等同于存储体积更小。

机器只读核验为 Ryzen AI Max+ 395 / Radeon 8060S，Windows 11 Pro build 26200，显示驱动 32.0.31032.1003，未装 WSL。项目内创建隔离 Python 环境，采用 PyTorch 2.8.0+cpu、FP32、8 线程。没有修改系统显卡驱动。

## 观测一：自然文本与层级粒度

原英文样本为 306 字节、48 个空格分词，节点数 306→95→38；平均第一层 3.22 bytes/node，第二层 8.05 bytes/node。用户认为接近单词／短语、尚未到句子粒度；据实测需进一步收窄：第一层细于单词，95 个节点包含子词与空白等切分，第二层较接近词／短语，也没有被训练成“一句一节点”的固定角色。

中文样本 267→253→8；Python 样本 206→113→62；重复字母 320→320→1；随机 ASCII 320→315→2。原版训练分布与形态明显影响跨层分配，小样本不能外推总体压缩率。

选择位置投影并非节点的完整语义范围。H-Net encoder 有因果历史，原版边界又有 lookahead 式时序；一个平均覆盖八个字节的落点，其 hidden 可以依赖更早内容。不能从显示片段的短小直接推出节点只知道该片段，也不能因此宣称存在句级抽象。[完整输出](../experiments/hnet/results/hierarchy.json)。

## 观测二：等长冗余对照

构建五种均为 560 个 ASCII 字节的输入：

- 同一句 `The red box holds 10 coins.` 重复 20 次：560→301→75。
- 相同模板只换两位数字：560→301→105。
- 相同模板更换等长颜色、容器、数字、物品字段：560→313→120。
- 不同内容的自然散文前缀：560→195→77。
- 固定随机种子生成的独立随机 ASCII：560→553→10。

前三项的匹配较强：新增字段变化时，第二级保留更多节点，第一级对只改数字几乎不变。散文与随机串同时改变内容分布，不能将五者当成经验证的严格信息熵阶梯。

同句重复 1/4/16 次时，分别为 28→16→6、112→61→21、448→241→63；第二层平均覆盖从 4.67 增至 7.11 bytes/node。这是有限的上下文依赖现象，不等于模型学会可重复调用的句子程序。

**推论与反例：** 随机串粗层节点很少，证明节点率不是输入信息量的直接读数；不能仅据此判定信息全丢失或压缩质量优异。独立随机过去对预测下一字符可能没有帮助，而以后要精确复述该编号是另一种任务。若要判断语义保真，须实际测试后续引用、解码质量及去除细路径后的行为。本轮没有这些结果。

## 外围遗忘：两边都不能用“保留／不保留全部 token”概括

**H-Net 公开实现事实：** 最外层每个输入／生成字节都经过 encoder 与 decoder；只有路由选中时才进一步调用内层，最内层 Transformer 不处理全部字节。外围 Mamba-2 以固定大小递推状态及短卷积保存历史；中间层 attention 有局部窗口；最内 Transformer 在配置上下文内保留粗节点 KV。因此它也有历史衰减和局部访问约束，不能说所有层永久保存每个细 token 的完整状态。attention 的窗口限制也不自动等于实现物理删除所有旧缓存。[官方 HNet.step](https://github.com/goombalab/hnet/blob/3673fe1217ebeb0d1438c7c71d58d32bdd190ec2/hnet/models/hnet.py)、[Mamba-2](https://github.com/state-spaces/mamba/blob/a6a1dae6efbf804c9944a0c2282b437deb4886d8/mamba_ssm/modules/mamba2.py)。

**v1.2 设计规定：** 外围 A/D 局部窗口和 B⁺ 开放单元缓冲有界，B⁻ scope 按调用／返回管理；已提交 F KV 在约定会话内保留。跨轮直接接续 latent，不默认将整段自产文字重新编码。EXPIRED、QUERY、RETURN、COMMIT 等规定可达性和寿命；这些显式协议不同于仅有 SSM 衰减，但还没有本项目实现验证。

## B⁺、B⁻ 与耦合模块

按功能对应，H-Net 的 encoder＋router＋downsample 类似读入侧 B⁺；默认压缩是选择边界处的上下文向量，不是额外对每个跨度做一次池化。dechunking＋decoder 类似粗到细表达接口，但其平滑、重复展开和字节自回归，没有实现 v1.2 的父计划、可变子调用、消费实际 RETURN 再决定后续的操作协议。

若“耦合模块”指 v1.2 §4 的双路加法可逆块，H-Net 的普通 Mamba／attention／残差没有同样的结构性逆和 A/D 参数绑定。H-Net 的 fine-grained skip 也不能当作这个可逆耦合。v1.2 同时明确 B 的有损规约不要求可逆；不能反过来声称 B⁺ 与 B⁻ 本身严格互逆。

这些均只与已公开 H-Net 对比，仍不能据此排除 Cartesia 内部实现重合。

## 暂定结论、未决问题与下一步

已经获得可重复读取的两级路由观测，支持内容／上下文相关的节点分配；没有证明句级语义规约、长期精确保真、完整本地生成或训练复现。平均跨度与隐状态的信息范围分开解释。

下一步可对随机编号的后续精确引用设置任务，并比较外围可访问／过期条件；需要完整生成／任务路径与干预，不能只看本探针。GPU 部署、官方内核对照、更大／中文权重对照分别留待明确执行。此后扩展样本应固定模型、输入约定和测量定义，不能把更换权重造成的变化混同于单一冗余因素。
