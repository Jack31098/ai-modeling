# 三模型本地词组标注试跑

开始于 2026-11-04 夜间，主要执行与复核在 2026-11-05（America/Los_Angeles）。用户授权下载几个实用模型，依据 v1.2 词／词组要求运行同样本，并由 Codex 抽样目测比较。395／128GB 是测试机，MI300 是后续正式生成硬件；本轮没有租机、使用付费 API、升级全局驱动或操作别人的进程。

## 对象、假设与交付边界

比较外部结构 teacher，不选择学生 F 底座。延续 B 先训、F／最终展开器从头训练的口径。以 v1.2 §10 为准，当前只做 **READ_FULL 词／词组候选**，不把离线整段观察的树强制执行成早期 READ_STREAM 动作。

程序检查 JSON、逐字还原、Unicode code point／UTF-8 区间、覆盖、预算和部分词单元约束；词义、局部词组、否定／条件／角色关系由 Codex 审阅。硬检查通过、Codex 主观评价、独立人工金标分别报告；目前没有第三种。保留空白和标点的节点数不是语义压缩率。

本轮不是完整 D1：尚缺学生 tokenizer 对齐、可执行 B+/B- 事件编译、先预测再 forcing 的真实消费器、RETURN／耦合／遗忘专项数据及神经连续状态学习。所有样本保持 `training_eligible=false`、split null，不更改旧发布包。

## 可观察事实

已复用并完整重验 Qwen3.6-35B-A3B Q8_0（36.90GB），新下载 Qwen3.8-27B Q8_0（29.05GB）和 GLM-4.7-Flash Q8_0（31.84GB）。三者固定 Hugging Face revision、字节数与完整 SHA-256，均为公开免登录的 Unsloth GGUF 转换。原厂模型与转换者区分记录，不将 Q8 结果当作 MI300 BF16／FP8 成绩。

使用官方 llama.cpp b12125 Windows Vulkan 包，同一上下文 8192、单槽、全 GPU offload 请求、温度 0、seed 7391、输出预算 2048、关闭思考和同一 JSON schema。每次只载入一个模型，只停止运行器自己创建的进程。完整命令、实际模板、设备与 offload 日志、原始请求／响应、计时及失败均保存。

参数量按作用范围分开：**Qwen3.6-35B-A3B** 为官方35B总量／约3B激活的40层混合注意力 MoE（256选8＋共享1）；**Qwen3.8-27B** 为64层混合注意力＋dense FFN，名义27B，不另造MoE式稀疏激活数；**GLM-4.7-Flash** 为官方30B-A3B、47主层、64选4＋共享1的MoE。见各自[官方卡](https://huggingface.co/Qwen/Qwen3.6-35B-A3B)、[官方卡](https://huggingface.co/Qwen/Qwen3.8-27B)、[官方卡](https://huggingface.co/zai-org/GLM-4.7-Flash)及实验中的固定 revision config。

按已校验 GGUF 的张量形状求积再求和，本地分别存储 34,660,610,688／27,320,697,856／29,943,393,920 个张量元素。Qwen3.8 内含424,699,392个额外MTP元素，去除后26,895,998,464；本轮实际 `speculative.types=none`，未启用MTP推测解码。官方全发布包的 safetensors总数是35,951,822,704／27,781,427,952／31,221,488,576，包含的组件范围不同，不能直接替换本地文字核心计数。精确元素数不等于每token触碰数；激活3B采用官方近似口径，绝非以Q8文件大小代替参数量。`parameter-summary.json` 保留这三种范围，`model-evidence/`保存配置hash及完整张量目录；没有为了补证据重跑样本或重下载权重。

28 条首轮样本包括 24 条自编诊断和原 v0.2 的四条 MDN 中英自然摘录；有“研究生命起源／研究生命科学”、角色、否定、条件、数量、英文歧义、Unicode、空白、代码及引用指令。另预先冻结八模板的 72 条变体，构成每模型 100 条；模板变体不是独立自然语料。

提示、输入、预算及 12 条主审阅样本在推理前固定。每条至多一次因硬失败／截断触发的修复，不作语义 best-of-N；保留所有尝试。Codex 对每个模型同样的 12 条逐项阅读原始输出，另看其他首轮硬失败。审阅者参与了准备和运行，**不是盲审或独立人工金标**。四条自然摘录现已用于探索性选择，新协议验证需另取新保留集。

首轮 28 条：Qwen3.6 首次／重试后硬通过 13／13（15 次重试）；Qwen3.8 为 15／20（13 次重试）；GLM 为 3／4（25 次重试）。四条自然文本中 Qwen3.8 通过三条，其余两者均零条。硬通过不能写成语义准确率。

这 28 条含重试的客户端标注时间分别为 122.91／586.97／144.67 秒，不含加载。输出 token／标注墙钟秒分别 26.43／5.67／27.25；输出长短不同，失败开销计入。该组没有撞到 2048 输出上限，也没有返回思考文本。GLM 的本地速度优势不等于质量合格样本／卡时优势，更不是 MI300 吞吐实测。

## 最小例子与反例

三者对“研究生命起源”的选定结果都得到 `研究｜生命｜起源`，对“研究生命科学”允许 `研究｜生命科学`。这不是中文唯一金标。旧 `研究生｜命` 是有界 FMM 反例，不属于离线 jieba；其旧参考是 `研究｜生命｜起源`。

Qwen3.8 将“如果甲没有交款，乙就不发货；除非丙先确认。”分为三个保留标点的局部组；Qwen3.6 将全部放进一个组，最后孩子竟是 `丙先确认。`，虽硬检查通过却不是合格词单元。这证明当前检查器不能替代词／词组质量审阅。

Qwen3.8 对英文 Unicode 自然段保留原文并生成大致合理的词组；对中文 Unicode 自然段却在 12 子节点处把 `很困难｜的，` 拆成不同组。预算满足不代表结构有用。

GLM 的 `Dr. Reed / can't re-enter / the U.S. office / at 3.14 p.m.` 分组常比单词碎组自然，但省掉所有间隔，不能映回完整原文。其他例子还漏掉“不是所有申请**都**被拒绝”中的第一个“都”，把 `+1,234.50` 拆开；不能假定全部错误都能无损补空白。

模板补充抽查按每模板第一条（000–007）确定范围，不加入预定主样本分母。其中 GLM 对 expansion:005 将 **“不是说”重排为“说不是”**，这是涉及否定作用域的真实原文顺序改写；与单纯漏空格区分。保留全部词也不代表保持原句关系。三者各八条的补充评语单独保存在 `codex-review.json`。

Unicode 例中 Qwen3.6 破坏 scientist emoji 并插入换行；Qwen3.8／GLM 保留组合字符及 emoji 较好，但仍分别违反空白单元或原文保真要求。没有证据把所有失败归因于 tokenizer。

## 暂定判断与下一步

在**当前冻结的复制原文接口**下，Qwen3.8-27B 是继续试制较合适的主基线；词组候选及保真存活率比另两者可用。但三者均未达到可直接生产 D1 的程度，当前结果不构成模型固有语言能力或 MI300 生产吞吐的排名。

下一接口建议固定低层节点与 ID，仅让 teacher 给上层有序分组／边界，程序保存空白、标点及原文字节；与 v1.2 §10.5 一致。它**可能**减少复制失败，尚未实测，不能据此宣布 GLM 已获救或获胜。用新保留自然文本确认，再做 tokenizer／事件／消费器验收及 MI300 BF16/FP8 同卡同负载测试。

72条模板扩展已完成：Qwen3.6 首次／最终42／42（30次重试）；Qwen3.8 为28／42（44次重试）；GLM 为0／0（72次重试）。两Qwen在此同模板组最终硬通过持平，Qwen3.8还需更多重试，不能把首轮相对优势扩写成普遍胜出。全100条首次→最终为55→55／43→62／3→4，合计499次尝试（145／157／197），没有传输错误、输出上限截断或返回的思考文本。

全100条含重试、不含加载的标注时间为343.02／2069.48／415.31秒。混合模板组的聚合存活数不作独立自然语料准确率。预定主审阅36份、模板补充24份，其他首轮硬失败另记。8项针对性测试及300记录审计通过；输入／请求／原始响应、固定协议、hash、参数范围和所有六个本任务服务的退出均可追溯。Windows主动终止服务的退出码1有专门说明，不冒充推理崩溃；未停止其他人的进程。
