# 层深、语义抽象与输出阶段（2026-10-02）

## 问题、对象与术语

用户指出之前的架构讨论缺少可落地的检验，并质疑“越靠近顶层越抽象”。直觉是：中高层可能最擅长整合语义，末层要把状态转为输出 token，可能更侧重局部形式。先讨论已训练的 decoder-only、full causal attention LLM；“高层输出语义 token，再表面化”的新架构另列为假设。常规 LLM 的末层输出是词表预测，并没有单独定义的“语义 token”。

- 理论可见范围：位置 i 在第一层即可访问整个前缀 x_1:i；标准 full causal attention 的可达范围不会随深度必然缩小。
- 实际使用范围：平均注意距离、远处事实的因果贡献、前层已汇入当前位置的信息是不同量。顶层少直接读取远处位置，不等于顶层状态没有远距信息。
- 抽象程度没有唯一标尺。词义、篇章关系、规则、未来多 token 内容和输出格式可能在不同层、位置、任务上各有峰值。probe 可读出信息不证明该层在使用信息。
- 可观察量：逐层语义/结构可读性、远处证据的因果影响、对最终词表分布的贡献，以及实际计算成本。

## 已核查的研究（仅限各自模型与任务）

1. [Liu 等，Findings ACL 2024](https://aclanthology.org/2024.findings-acl.866/)在 Llama 2 的语境词义识别中发现低层已编码词汇语义，高层该指标较弱、趋向预测。这反对末层必然是最佳语义表示，但不能证明中高层承载所有抽象语义。
2. [Tikhomirova 与 Wulff，Findings ACL 2026](https://aclanthology.org/2026.findings-acl.1008/)跨 10 个 encoder/decoder 模型测 58 种心理语言特征：末层很少是线性读出最好的层，峰值又依赖特征和提取方法。词汇属性较早，经验/情感维度较晚。
3. [Future Lens，CoNLL 2023](https://aclanthology.org/2023.conll-1.37/)在 GPT-J-6B 中发现，所用读出法对更后续 token 的预测在中层最好，对紧接下一个 token 则在末层最好。这与“中层保留较宽未来信息，末层对齐即时输出”相容，但只是可读性证据，且只测一个模型。
4. [Lad 等，2024](https://arxiv.org/abs/2406.19384)根据删层、换层及表征实验，提出早期局部信息整合、中期特征构建、后半段逐渐贴近词表预测、末层锐化分布的阶段性假说。作者未证明四阶段是通用定律。
5. [Artzy 与 Schwartz，BlackboxNLP 2024](https://aclanthology.org/2024.blackboxnlp-1.10/)在四个 LLM 和四类任务中发现，扰动后 30–50% 层供未来 token 读取的旧位置状态往往影响较小，较早层同类扰动影响更大。作者推测前段收集信息、后段更多在当前位置处理；后段并非已证明只做文法。
6. 关键反例：[Vig 与 Belinkov，2019](https://arxiv.org/abs/1906.04284)在 GPT-2 small 发现，注意力与依存关系最强对齐在中层，但最深层平均注意距离最长。“顶层实际范围必然回缩”因此没有通用依据。[心理算术因果干预研究，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1565/)还发现某些重要计算在很晚的层、最后一个位置发生。

## 最小实验与竞争预测

固定一个开放权重 decoder-only 模型，不改参数。配对输入：前段“甲把钥匙交给乙”，长干扰段后“原报告有误，收件人应为丙”，尾部问“现在应找谁”；对照只改变纠正语句，保持尾部相同。另设局部标点/词形选择，以及不依赖远距事实的对照。对每层同一读取位置测：固定容量 probe 的准确率、下一词和后续数词的读出质量、远处纠正信息的激活替换/路径干预对答案 logit 的影响、分层注意距离。probe 用独立测试集；注意力权重和 probe 分数不直接视作因果机制。

- 单调抽象假设：语义/长程变量随层数持续改善；若多类语义指标及因果影响稳定在中层达峰，它受到削弱。
- 中层整合、末层输出适配假设：中高层更易读出篇章/规则，末层增量主要改善即时词选择、格式或校准；若晚层仍对远处事实进行重要计算，则“末层只是表面化”受到削弱。
- 任务/位置依赖假设：不同变量和任务的峰值不同；只有跨模型、任务、位置重复同样分层，才有理由提出更强规律。

需分别干预 attention 与 MLP，并区分状态中已有的信息与某层新增的计算。残差连接可将较早整合的信息保留到顶层，简单删层不能直接定位信息形成时刻。

## 暂定结论、失败条件、未决问题与下一步

已有 decoder-only 研究支持“末层偏向即时预测，部分语义最佳读出在非末层”，但不支持“中高层必然最抽象”或“顶层感受野必然回缩”。更可检验的表述是：模型可能先整合并保留多种信息，随后逐渐把其中一部分转成当前输出决策；层位随任务而变。

若要构造内部语义状态与逐 token 输出分离的新架构，应显式定义“整合状态 → 读出/表面化”接口，而非假定现成层号天然对应。先验证逐层分工是否稳定，以及从中层状态接轻量读出器能否在质量和总成本匹配下产生净收益。失败条件：中层 probe 很好但干预不改答案；跳过末层损伤远距推理而非仅格式；读出器成本抵消节省；结论只在单模型或单任务成立。

未决：这里的“语义 token”指离散 code、连续状态还是片段级对象？主要优化长程信息使用、生成延迟、活动内存，还是模块池的训练可行性？这些决定后续接口和实验。
