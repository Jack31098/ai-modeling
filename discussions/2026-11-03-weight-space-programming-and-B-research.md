## 1. 问题、对象与证据口径

这里的 B⁺ 包括边界控制和有序组合，B⁻ 包括展开、停止和父子结果更新。F 指最终真实消费这些状态的核心网络；一个新写的字段读取器不自动等于原 Qwen F。父节点、开放 scope、子结果和已提交历史是不同状态，须分别记录可见范围、形成时间和寿命。

核心问题是：能否借助权重空间的直接构造或局部修改，使这些接口更容易定义、观察和检验？继而检验多级状态是否保留了后续任务真正可用的区别。不能从“规则可编译进权重”直接跳到“自然语言语义可以无训练地普遍编译”。

## 2. 外部公开结果：能借鉴到哪一步

[Takehi 等的研究博客（2026-11-02）](https://rikiyat.github.io/blog/weight-space-programming/)报告：通用 LLM 可直接读写权重。Qwen3.5-0.8B 实验在无梯度、允许 50 次前向反馈的条件下，编辑 131,072 个权重以缓解循环；MATH-500 从 7.9% 到 48.1%。同文也报告 Gemma 270M 未获明确数学提升，以及仅靠权重未能识别迎合行为，加入注意力观测后才成功。这是作者公开报告，尚非本项目复现。

因此，“修复一个可定位故障”“编写已知规则”和“获得新语义能力”应分别验收。外部结果提供研究动机，不证明我们的 B、跨模型迁移或多级路线已成立。可追溯材料见作者的[实验日志仓库](https://github.com/RikiyaT/lm_understand-logs)。

## 3. 我们已有的结果及其边界

### 3.1 同一词典不等于同一表示或兼容接口

归档检查显示，0.8B、2B、27B 的 `tokenizer.json`、`vocab.json`、`merges.txt` 逐字节相同，冻结的 13 条裸文本切词也相同。27B 的聊天模板和 thinking 默认设置存在差异；“相同 tokenizer”在这里指基础切词与 token ID，不能说全部聊天配置字节相同。

三个输入表宽度为 1024、2048、5120。0.8B/2B 绑定输入与输出表，27B 两表独立。复用 27B 的“词典”没有换词条，真正的候选变化是训练后的向量与训练信号。不同表的同维投影也不自动处在兼容坐标系。

### 3.2 有限解析器证明了规则编译，没有证明通用语义 B

代码和元数据对应的计算为：35 个 token 原型 → 28 个词类 → 11 状态的 ReLU 转移 → 22 个输出字段。递归逐 token 更新内部状态，但只在整句处理结束后输出一次父态；没有内容驱动的多次规约、B⁻ 展开或真正的 child RETURN。

它支持 8 个名字、3 类水果、两种主动句模板、正整数和局部 `does not give`。在同一有限文法内，随机 1000 个未见组合全部通过；替换为随机单位 token 编码并重建身份原型后，也全部通过。这里的“未见”是组合未参与构造，不是自然语言泛化。

本次在 NumPy 2.3.5 / CPU 上提取归档的 `forward`、`consumer`、`random_code` 函数，仅执行数值重放，结果为：

| 输入条件 | 与保存的 expected 完全一致 |
|---|---:|
| 保存的归一化原型方向，按原 token ID 取值 | 1000/1000 |
| 原固定种子随机编码与随机对照权重 | 1000/1000 |

第一行没有重新加载官方 embedding；它验证保存原型、转移权重、样例和消费者的一致性。两行均没有运行 Qwen 网络，不能计作新的模型语义验证。

角色交换、父态屏蔽、否定字段消融表明**新消费者**会使用父态；这没有证明原 Qwen F 会读该 22 维编码。未知名字、接收式改写、嵌套句、单位、负数、小数等被拒绝，拒绝不算理解。

用户另补充：两条专业句分别为 35/36 token，首 token 即被拒绝。本轻量包中未定位到对应的逐 token 轨迹，因此目前记为用户报告的边界观察，未声称本次独立重跑。补齐原句、token ID 和首个拒绝状态后，才能成为固定回归样例。它与代码的有限词汇支持相符，但不能据此推断所有神经组合器都会失败。

### 3.3 27B 压到 1024 维已有诊断结果，学生迁移仍未验证

归档投影使用 4096 个拟合 token、2048 个审核 token，排除固定探针词；输入表和输出表分别拟合。方法是对归一化样本的未中心化近似 SVD，另保留固定随机正交投影对照。它是**无标签、无梯度的数据拟合**，不是完全无数据构造。

1024 维的部分结果如下，均为手选小词集诊断：

| 表示 | 四类词分类 /16 | 同义比对立词更近 /8 | 数字邻接 /10 |
|---|---:|---:|---:|
| 27B 输入原表 | 16 | 3 | 9 |
| 输入低秩 | 15 | 2 | 9 |
| 输入随机投影 | 16 | 5 | 9 |
| 27B 输出原表 | 15 | 4 | 10 |
| 输出低秩 | 13 | 5 | 5 |
| 输出随机投影 | 15 | 3 | 10 |

低秩保留更多能量，却未普遍胜过随机投影。此结论限定于这次采样、目标、秩与小探针，不否定其它压缩方法或联合适配。词级分类、角度保持和数字邻接不能代替角色组合、数位解析、作用域或学生语言能力。

归档记录含 12 组结果重评及原行乘基核验；本次读取了这些历史记录，没有重建缺失基、重新下载 27B shard 或重做全表投影。**大词表示给小模型初始化/蒸馏、BF16 后复测、与原 F 的兼容性仍待研究。**

## 4. 由证据得到的研究推论

以下是我们的推论，不是外部论文或既有实验已经证明的结论。

1. **先编程协议，再研究语义。** 可直接构造 scope 生命周期、计数、合法调用和返回检查，用于验证执行器；是否学会开放语言内容，要由新的组合和迁移测试回答。把两类任务分开有利于定位失败。
2. **观察状态比给 latent 命名更有价值。** 保存各层状态、形成时刻、来源、实际消费记录和失效原因，可以检验哪一步丢掉了角色、数位或否定；不要求每个向量等于人工摘要。
3. **多保留状态可能带来研究价值。** 同一顶层答案下仍可能存在不同的中间事实、冲突或不确定性。若后续任务能通过合法访问利用它们，就有可测的信息增量；多建几层、增大状态数或探针读得出来本身都不充分。
4. **可读出与可使用须分开。** 探针能解码只说明在指定读出条件下有信息；要证明状态参与任务，还要做删除、替换、交换和读权限消融，观察真实消费者的变化。
5. **不把无梯度当成研究信条。** 解析构造、无标签投影、监督训练和局部权重编辑可以分别比较。若联合学习更有效，仍符合 v1.2 的参考规约与任务梯度路线。

## 5. 可检验假设与公平比较

| 假设 | 最小比较与可支持的观察 | 反例或证据不足 |
|---|---|---|
| H1：额外可达的中间状态能帮助后续任务 | 提问在状态形成后才揭示；比较完整访问、仅父态、删除/交换指定子态；答案按被干预事实改变 | 只有探针改善，真实任务不变；或读出了未来答案/不可见原文 |
| H2：多级调用有可组合价值 | 单级与两级处理相同事件流；在未见嵌套组合上检验 RETURN 改变下一 child，且开放/关闭与超时可追溯 | 只在固定树/固定长度通过，或父程序忽略实际返回而重读答案 |
| H3：27B 表示给学生带来增量 | 同 tokenizer、学生宽度、数据、训练步数与评价；比较学生随机初始化、0.8B 表、27B 输入/输出的低秩与随机投影 | 只改善小词探针；训练后任务无稳定差异；控制条件获得更少适配机会 |
| H4：局部权重修改能修复定位明确的接口故障 | 冻结基线和验证集，记录修改张量/理由/反馈预算；同时检验修复与原能力回归 | 仅在用于编辑的样例提高，或修复依赖隐藏回退、答案泄漏 |

H1 与 H2 必须拆成两个问题：**多给信息有没有用**，以及**在相同可用信息下分层组织有没有用**。因此至少保留以下对照：

- 单级父态；单级加可访问明细状态；多级只读顶层；多级允许合法读回。单级加明细可以用普通状态表，不强迫它也长成同一棵树。
- 所有路线使用相同输入、查询时点、监督来源和数据划分；分别运行参考结构条件与自主控制条件。
- 同时给出相同总状态容量的比较，以及各自自然配置的比较；前者回答组织作用，后者回答候选整体行为。额外容量带来的收益应如实归因。
- 参数量、状态字节、调用数、延迟和适配量完整记录；尽可能做预算匹配的补充比较，但近期不以更快或更省作为保留某路线的前提。

不能只给多级方法子状态读回而禁止单级保存同等信息，再宣布层级更优；也不能只凭单级更省就结束对多级可观察性的研究。即使单级任务分数更高，多级若提供可重复的错误定位或状态干预证据，仍可保留为研究工具；这种价值与任务性能优势分别报告。

## 6. 下一步按可观察闭环推进

### A. 固定证据与最小数据协议

先固定原包、代码、种子、输入 ID、预期字段和版本清单。本次数值重放已完成；还未复现的专业句轨迹和大投影明确留空。数据每条事件至少记录：`episode_id / event_id / scope_id / parent_id / action / available_at / observable_payload / target / target_visibility / state_before / state_after`。监督字段与部署观测分开存放。

先做少量可检查事件，不先扩大 AI 标注生产。覆盖角色交换、73↔37、跨 token 数字、否定作用域、条件、单位、未知实体、同前缀多后续、信息缺失后补充。按内容族、模板族及派生关系划分，避免同一底稿的改写落在训练和测试两边。

### B. 先验证状态消费，再训练组合器

沿用明确的有限任务作为起点，同时保存原始字段真值与执行轨迹。建立可运行的单级和两级执行器，先用解析构造验证 CALL/RETURN、生命周期、合法可见性和可控干预。**这一阶段的产物仍是协议/规则基线。**

随后在相同任务上比较有序学习组合器与规则基线。随机 token 编码必须保留；加入新词、新模板、长度外推和作用域组合时单独报告覆盖率与错误，不能把文法内 1000 个随机组合当作这些测试的替代。

### C. 完成一个真实的 B⁻ 与结果回流闭环

给定合法父计划，让 child 自己执行，返回实际结果，再由父状态决定下一次调用或结束。最小反事实是：父计划相同但第一个 child 返回不同数量/失败状态时，第二个 child 的行为应相应变化。目标侧完整展开、未来长度和标准 RETURN 值只能监督，不能提前喂给主路径。

分别报告参考动作＋文字 forcing、自主动作＋文字 forcing、自主动作＋自主展开。偏离参考轨迹后重新对齐或结束该监督片段。原解析器没有这个闭环；不能通过给现有函数改名来宣布 B⁻ 完成。

### D. 表示迁移和 Qwen F 接入分别验收

表示迁移先固定一个学生结构，避免同时更换词表、组合器、训练配方和层级深度。27B 输入与输出来源分开，随机投影保留，输出头不默认替代输入表。记录训练前后表现，判断收益来自初始化还是训练后的任务学习。

接入原 Qwen F 时，先列清真正的消费者接口，包括 hidden、位置与各层实际缓存/循环状态；不能凭宽度相同宣称兼容。允许训练桥接和联合适配，但须报告训练范围。最后关闭原细路径、教师和隐藏补算，检验连续运行、多轮接续与父态干预。新字段消费者通过，只能算新消费者通过。

这些阶段是递进的证据目标，不是已运行的训练计划。无须在第一轮同时完成大模型迁移、完整可逆 A/D、自由结构搜索与多层树搜。

## 8. 暂定结论与接续交付

目前最可靠的收获是：已获得一个可检查的规则编译负对照、一组词表示与压缩诊断，以及明确的接口缺口。它们足以设计下一次实验，尚不足以宣布通用 B、B⁻ 或大模型知识向小模型迁移已经成功。
