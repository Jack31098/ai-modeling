# 从 World Labs 到层次化可写记忆（2026-09-29）

来源：[ChatGPT 分享对话](https://chatgpt.com/share/6abc6e55-4634-83e8-b63a-c908678761c1)。本记录概括对话的 18 个用户提问节点；其中的产品、论文、交易和性能陈述均只作为**对话中的主张**记录，尚未独立核实。

## 问题与术语

- **对象**：多模态世界模型、机器人控制模型，以及可递归计算的语言模型架构。
- **尺度**：从单次推理中的 token/latent 状态，到跨任务保留的记忆；商业讨论另涉及公司与硬件生态。
- **目标**：比较世界模型与多模态 LLM 是否趋同；进一步寻找更省计算、能操作自身上下文的模型结构。
- **可观察量**：机器人任务成功率及成本、动作预测与空间一致性、推理准确率、延迟、计算量、记忆占用、细节回忆与误报率。
- **层次化记忆**：字面 token、局部语义块、事件/命题、概念等不同抽象层级的可寻址状态；此处是候选架构，不等同于现有 KV cache 的事实描述。

## 对话的推进

1. **World Labs 与多模态 LLM**：用户提出，若多模态 latent token 能同时承载语言、视觉、空间等信息，世界模型与 LLM 的架构可能趋同。此前助手以 World Labs 的 Marble、Atlas 为例，把剩余差异归在几何约束、动作条件状态转移、训练目标和状态保真度。这是对路线的解释，不能单靠产品描述证明完全趋同。
2. **商业与硬件插曲**：对话讨论了分享页所称的 AMD/World Labs 交易、Nvidia 与 AMD 的合作地位、收购对硬件工作负载的价值，以及 Thinking Machines、Liquid 为何可能更适合投资或合作。对公司动机和交易价值的判断均为推测；分享页中的交易本身未在本记录核实。
3. **机器人路线比较**：用户追问 World Labs 的模型能否成为机器人“大脑”，以及通用多模态 LLM 加 action head 和机器人数据微调能否达到相同上限。对话区分了仅外挂动作头与端到端训练，并认为前者可能缺少物理状态和控制能力，后者或许趋同。对话也认为 neural rendering/3D 重建是 World Labs 更直接可观察的用途。两条路线的成本与上限未被实验证定。
4. **recurrence 的边界**：用户质疑此前助手把 Liquid LFM2 当作 LTC 式递归网络。此前助手明确修正：其讨论中的 LFM2 是短卷积与注意力的混合，而 LTC 才是持续状态的递归结构。随后讨论递归对机器人连续感知可能有用，但并不自动适合需要精确回查原文的语言任务。
5. **从 Tiny Recursive Model 到 latent 草稿**：用户把重复操作状态的小 Transformer 与 LLM 的隐式思考联系起来，设想用 latent token 反复迭代，避免全部推理都序列化成文字。讨论区分只能 append/pop 的栈式记忆与能改写旧状态的可寻址记忆，并讨论 Coconut 作为“完整穿过所有层再循环”的一个特例。
6. **动态层级控制流**：用户提出输入时在中层把多个字面 token 压为语义块，高层只处理更稀疏的状态；必要时跳回低层查细节。输出时先让高层/中层迭代，再解码文字。由此，固定的 `token × layer` KV 缓存被设想为可合并、展开的稀疏树。此前助手建议用 teacher 引导压缩与路由，再用准确率、计算、内存和延迟的联合目标训练；这些都是待验证方案。
7. **选择性遗忘与主动上下文学习**：用户进一步提出，删除底层 token 而保留高层语义，可形成“记得大概”的选择性遗忘；若模型可读、写、删、合并、拆分及重排这些记忆，就能在固定慢参数的情况下，通过更新内部状态来学习。此前助手将其类比神经图灵机与主动的 in-context learning，同时指出：压缩后重构的细节可能是幻觉，记忆需要保存来源、保真度和不确定性。

## 最小例子与失败条件

- 输入：“Alice 在周二 15:17 把带红色钥匙扣的钥匙交给 Bob。”压缩为“把钥匙交给 Bob”可支持回答人物关系，却可能无法回答星期、时间或颜色。若底层已删除，模型应承认缺失，不能按常见模式猜测细节。
- 如果模型过早合并“交钥匙”和“Carol 进入之前”两个片段，可能丢失时间顺序；过晚合并则节省不了计算。
- 对机器人，压缩状态若无法预测动作后的物体位置，世界模型目标就未达成；对文档检索，若无法精确回查数字，纯递归压缩可能劣于保留原文的注意力或外部存储。
- 层次化路由的管理、索引与重新展开也有成本；只有在相同准确率与总预算下胜过固定结构，节省计算的主张才成立。

## 暂定结论与未决问题

**暂定结论**：这段对话从具体公司和产品出发，最终形成的核心思想实验是“动态多层计算图 + 可读写的层次化 latent memory”。模型可以在不同抽象层级计算，按需要压缩或展开状态，并用记忆更新承担一部分推理时学习。它是研究假设，未得到对话中的实验验证。

**未决问题**：何时压缩或跳层？如何保留可核查的原始证据？如何训练读写策略、避免幻觉和错误巩固？如何与固定 Transformer、普通摘要记忆、检索式记忆及参数更新方案在相同成本下比较？World Labs 与通用机器人模型各自的真实能力和训练成本也需另行核实。

**下一步**：设计一个同时要求“概括事件”和“精确追问细节”的小任务，比较完整 KV、固定压缩、可展开层次化记忆三种方案；分别测准确率、拒答校准、计算量和内存占用。商业事实与论文主张若要纳入模型依据，应逐项查原始资料。
