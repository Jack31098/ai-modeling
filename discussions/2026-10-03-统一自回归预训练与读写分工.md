# 统一自回归预训练与读写分工（2026-10-03）

## 问题与修订原因

用户指出上一轮跨度过大：应先回答预训练怎样进行。decoder-only 的吸引力包括用统一的语言建模训练处理各种文本模式；拆成 E/C/D 后，D 是否仍能被直接训练，是否只是回到 T5 的 encoder–decoder 路线？

这个批评指出了[分离读写路径与生成反馈](2026-10-03-分离读写路径与生成反馈.md)尚未交代预训练监督和计算图的问题。本记录以分块模型说明联合自回归目标的合法性，不证明固定分块具有语义层级。用户随后进一步要求增量分层训练，当前优先路线已改为[增量分层训练与层级生长](2026-10-03-增量分层训练与层级生长.md)，固定块 E/C/D 保留为因果分析与对照；W、完整输入修订及严格逆耦合均未解决。

本轮没有模型实现或训练结果。下文区分既有论文事实、合法概率分解、候选研究顺序与尚未证明的能力收益。

## 定义与需要分开的判断

- **架构**：是否由一个层栈或多个有不同职责的模块组成，是否有跨模块接口。
- **预训练目标**：纯因果语言建模、前缀条件语言建模、span corruption 等；这些不能由“有无 encoder”直接判定。
- **监督覆盖**：一次处理的原始文本中，哪些 token 经输出分布计算损失。全部 token 都被预测，与只预测后缀或缺失片段不同。
- **任务统一**：普通文本、对话、问答、代码等都能按同一文本续写目标处理，不要求预先给每种内容设任务头。这个接口不自动保证模型学到所有任务。
- **双向已知输入**：仅影响已经给定的上下文，不得让当前预测目标通过其他模块进入条件状态。
- **当前目标与可观察量**：先确认 E/C/D 能否用同一因果语言建模损失联合训练，再比较 loss、块内位置 loss、续写/上下文学习、压缩信息损失，以及训练和推理成本。

## 关于 T5 的事实与上一轮方案的位置

[T5 原论文](https://jmlr.org/papers/volume21/20-074/20-074.pdf)本来就把多种任务统一为 text-to-text；其 encoder 和 autoregressive decoder 可以端到端训练。标准 T5 采用缺失片段恢复的 span-corruption 目标，但论文 §3.2.3、§3.3.1 也研究了随机分成前缀输入和后缀目标的 Prefix LM。

[UL2](https://arxiv.org/html/2205.05131v3)进一步区分这些目标：S-denoising 是前缀/后缀的顺序划分，R-denoising 接近 T5 的常规 span corruption。它也说明预训练目标与 encoder–decoder/单栈架构可以分别选择。

因此，上一轮随机切一次前后缀、双向编码前缀、只监督后缀的方案确实属于 encoder–decoder/Prefix LM 方向。它可以训练 D，并非无效，但不能只凭“仍算交叉熵”就声称完整保留了 decoder-only 的全位置监督和训练方式。也不能仅靠它不同于 span corruption 来回避用户指出的相似性。

## 保留全部 token 监督的候选基线

把一段普通训练文本分为固定长度块 b_1,…,b_K，初始先用小块，不为它们人工分配“输入任务”或“输出任务”。定义：

- z_k = E(b_k)：读入已经完成的块。块内可以看见该块的全部 token。
- h_(k-1) = C(z_1,…,z_(k-1))：用块间 causal mask 整合历史；当前块 b_k 不在其中。
- D 预测 b_k 内的 token；第 j 个预测只能读取 h_(k-1) 和 b_k 中第 j 个 token 以前的内容。

完整概率分解是：

p_theta(x) = product_(k,j) p_D(x_(k,j) | h_(k-1), x_(k,<j))。

损失是：

L = -sum_(k,j) log p_D(x_(k,j) | h_(k-1), x_(k,<j))。

第一块使用空历史/BOS 状态；最后不足一块的有效 token 仍可计入，padding 不计入损失。这里是合法的全序列自回归分布：每个条件只依赖过去，输出分布归一化；其监督仍覆盖全部有效 token。它改变了模型的条件信息接口和表达能力，并不保证与普通 dense decoder-only 得到相同的概率或质量。

### 最小例子与联合反传

文本 ABCD | EFGH | IJKL：

1. D 预测 ABCD 时只取更早历史和当前块此前字符，不能取 E(ABCD)。
2. ABCD 已成为完整历史后，E(ABCD) 经 C 为 D 预测 EFGH 提供条件。
3. EFGH 完成后，同样成为预测 IJKL 的历史。

每一块既是一次生成目标，也是之后的输入上下文。D 为所有块、所有有效 token 计算交叉熵；预测后续块的梯度经 C 进入 E。E/C/D 从一开始联合训练，不单独训练一个脱离上下文接口的 D，也不需要先有人工标注的“语义 token”。

teacher forcing 时，真实 token 虽在内存中已知，目标对应的计算图仍只能访问因果允许的信息。E 可以并行编码各块，C 使用块间因果 mask，D 使用移位后的历史块状态和块内因果 mask，因此不必在训练前向里逐块采样。关键是 block shift：E(b_k) 只能服务更晚块的预测。

错误反例：将整个 EFGH 的编码喂给 D 再预测 EFGH，或让 C 双向看所有块再用于各块预测。即使 D 内部有 causal mask，其他路径也已泄漏目标；不能据此报告预训练有效。

### 直接研究先例与限制

[Block Transformer](https://arxiv.org/html/2406.02657v2)的 §2.3–2.4、§3.1 提供这种块尺度历史与局部自回归预测的直接训练先例。它在原始语言建模语料上从零训练全局 block decoder 和局部 token decoder，而非仅训练下游输入→答案任务。

其结果同时限制了“D 只需承担少量文法”的先验：§3.3 显示两侧容量都会影响性能，主设置采用较均衡的参数分配。当前不能预设读入/核心包揽全部语义、D 因而必然很小。这个先例也不证明更大块的强压缩或本项目完整架构已具优势。

## 与两种目标能力的对应，以及尚未满足的部分

### 输入时省掉输出模块：推理阶段有明确机制

当 prompt 已给定时，完整历史块只需走 E 和 C；为了预测之后的文本，没有必要计算这些已知块当初的 D 输出。这个省略成立的结构前提是未来 D 只依赖 E/C 的历史表示，不依赖旧块的 D 缓存。若 prompt 在块内结束，仍需要处理局部已知前缀。

但预训练时为了监督全部语料，D 仍处理全部目标位置。这是推理读入路径可以省计算，不是宣称预训练同样免掉 D。

### 输出时完全跳过 E：基线尚未实现

生成当前块时，D 无需每个 token 调用完整 E；但块完成后，基线仍通过 E 将实际 token 变成下一块的历史。若 E 只是便宜查表/拼接，这个代价较小；若 E 是深层读入网络，输出免重读仍是独立问题。

W 可以以后作为替代反馈对照，但当前先暂停其优先级。没有统一基线的质量和接口证据，先讨论写回蒸馏无法回答基础预训练是否可靠。

### 整个已知 prompt 双向修订：不能由当前基线直接外推

块内已经完成的历史可整体编码，块间的当前基线仍是因果的。最新核心状态可以综合历史，但早期块的状态不会自动被后文改写。这只覆盖“一目十行”的部分目标。

若要求整个 prompt 的早期状态都吸收后文，有三种条件不同的路线：

- 在已完成历史块内开放双向交互，保留块间因果：与上述单次、全位置预训练直接相容，但全局修订有限。
- 在随机边界前双向读取，之后预测后缀：可以自监督训练，属于 Prefix LM；一次样本只直接监督目标部分，需评价数据利用、续写分布与模式切换。
- 对每个预测位置重新双向编码其完整历史：数学上仍能保持纯自回归目标，没有未来泄漏，但朴素实现会重复处理大量前缀，失去简单单次前向的成本优势。

所以不能声称双向理解与纯 AR 在数学上绝对不兼容，也不能一次双向编码整篇后，用同一套已含未来的表示预测整篇各位置。额外全局修订机制如果采用，也必须明确它在训练和推理何时执行及其成本。

## 暂定结论、失败条件与下一步

暂定结论：拆分职责不必放弃全部 token 的统一因果语言建模；D 可以获得监督，E/C 通过同一输出损失联合学习。上一轮指定的前缀/后缀方案确实接近 T5 论文研究过的路线。本记录的分块基线仅证明一个合法训练图；用户指出固定分组与增量生长缺口后，不再把它作为下一步优先架构。

失败条件包括：

- 模型只在目标泄漏的训练图上 loss 很低，部署时质量崩溃。
- D 主要靠局部文本，忽略 C；跨块关系和上下文学习明显受损。
- 压缩损害名称、数值或条件约束；额外细节通路抵消成本收益。
- 保留同一损失却在资源匹配对照下需要过多训练计算或参数才能达到目标质量。
- 完整块输出的 E 重读成本高，且后续替代方案无法保持质量；两种能力中的第二项仍未成立。

因果图、监督覆盖和预算匹配检查继续适用于候选模型。当前下一步改为保留已有函数地训练新增一层，再检验新增层能否低频更新；每次只增加一个可验收能力，见[增量分层训练与层级生长](2026-10-03-增量分层训练与层级生长.md)。固定分组不等于语义粒度，完整 E/C/D 联合训练也未给出逐层扩展路径。本轮仅做思想实验，未运行训练。
